### 【考点1】管理用财务报表的编制
#### 整体框架

（1）总体思路：将资产拆分为经营资产和金融资产，将负债拆分为经营负债和金融负债。

（2）基本等式
净经营资产 = 净负债 + 股东权益 = 净投资资本

其中：
净经营资产 = 经营资产 − 经营负债 = 经营营运资本 + 净经营长期资产
净负债 = 金融负债 − 金融资产

【原理】
金融资产 + 经营资产 = 金融负债 + 经营负债 + 股东权益
经营资产 − 经营负债 = 金融负债 − 金融资产 + 股东权益

#### 2.管理用利润表
（1）总体思路：将净利润拆分为经营损益和金融损益。

> 净利润 = 经营损益 + 金融损益
>=税后经营净利润 + (−税后利息费用)
> =$EBIT\times(1-T)+[-利息费用\times(1-T)]$

（2）基本等式
净利润 = 税后经营净利润 − 税后利息费用
> 金融损益和税后利息费用，金额在方向上是相反的

【小帕提示】此处的利息费用为广义的利息
应以财务费用为基础进行调整，加金融资产相关的损失，减金融资产相关的收益

#### 3.管理用利润表结构

| 经营损益                 | 注意事项                         |     |
| -------------------- | ---------------------------- | --- |
| 一、营业收入               |                              | ——  |

| 加：营业外收入              |                              |     |
| 减：营业外支出              | 历年真题尚未涉及                     |     |
| 二、税前经营利润             |                              | ——  |
| 减：经营利润所得税            | 税前经营利润 × 平均所得税税率             |     |
| 三、税后经营净利润 √          | ——                           |     |

|金融损益|注意事项|
| ---- | ---- |
|（广义）税前利息费用|——|

【小帕提示】
（1）从管理用利润表结构中可得出：
①税前经营利润 − 利息费用 = 利润总额（利润总额一分为二，税前经营损益和税前金融损益）
②经营利润所得税 − 利息费用抵税 = 所得税费用（所得税费用一分为二，经营利润交的税和利息费用抵的税）
③税后经营净利润 − 税后利息费用 = 净利润（利润总额 − 所得税费用 = 净利润）

（2）平均所得税税率
原则上：平均所得税税率 = 所得税费用 / 利润总额（从传统利润表已知数据推算）
但在做题时，需要全面阅读题干内容，看题干是否要求根据各项损益各自适用的税率分别计算，否则应根据平均所得税税率计算，**不能直接采用企业适用的所得税税率**

#### 4.管理用财务分析体系—改进的财务分析体系
（1）核心公式
权益净利率 = 净经营资产净利率 +（净经营资产净利率 − 税后利息率）× 净财务杠杆
【简记】$ROE=A+(A-B)\times C$

（2）基本框架
权益净利率
= 净经营资产净利率 + 杠杆贡献率
  净经营资产净利率 = 税后经营净利率 × 净经营资产周转次数
  杠杆贡献率 = 经营差异率 × 净财务杠杆
    经营差异率 = 净经营资产净利率 − 税后利息率

（3）权益净利率的驱动因素分解（连环替代法）

|步骤|计算（不走回头路）|差异说明|
| ---- | ---- | ---- |
|基期|$ROE_0=A_0+(A_0-B_0)\times C_0$ ①|——|
|替代A因素|$ROE'=A_1+(A_1-B_0)\times C_0$ ②|$\triangle1=$②−①：A因素变动对ROE的影响|
|替代B因素|$ROE''=A_1+(A_1-B_1)\times C_0$ ③|$\triangle2=$③−②：B因素变动对ROE的影响|
|替代C因素|$ROE_1=A_1+(A_1-B_1)\times C_1$ ④|$\triangle3=$④−③：C因素变动对ROE的影响|

【小帕提示】报告期相对于基期的变化：$\triangle(ROE_1-ROE_0)=\triangle1+\triangle2+\triangle3=$④−①

#### 5.管理用现金流量表
（1）总体思路：将现金流量分为经营活动现金流量和金融活动现金流量。

（2）计算方法
**实体现金流量（来源）**
公式1：剩余流量法（毛净实三步法）
> 实体现金流量 = 税后经营净利润 + 折旧与摊销 − 经营营运资本增加 − 资本支出
> 资本支出 = 净经营长期资产增加 + 折旧与摊销

> 营业现金毛流量 =税后经营净利润 + 折旧与摊销
> 营业现金净流量 = 营业现金毛流量 − 经营营运资本增加
> 实体现金流量 = 营业现金净流量 − 资本支出

【注意】折旧与摊销为**当期计提**的折旧与摊销，而非累计数

公式2：净投资扣除法
> 实体现金流量 = 税后经营净利润 −（经营营运资本增加 + 净经营长期资产增加）
>         = 税后经营净利润 − 净经营性资产增加（实体净投资）

公式3：实体现金流量 = 债务现金流量 + 股权现金流量

**金融现金流量（去向）**
- 债务现金流量 = 税后利息费用 − 净负债增加（债权净投资）
- 股权现金流量 = 股利分配 − 股权资本净增加 = 净利润 − 股东权益增加（股权净投资）

【小帕提示】两个“增加”的区别：
①股权资本净增加（外部）= 股票发行 − 股票回购
②股东权益增加（整体）= 期末股东权益 − 期初股东权益 = 股权资本净增加 + 当期利润留存

【小帕提示】管理用财务报表之间的数据勾稽关系

# 【考点 2】资本需求与增长率的测算

## 1.销售百分比法预测外部融资需求

### 步骤

1. **第一步：计算融资总需求** 融资总需求(=)净经营资产增加 (=)基期营业收入(×)营业收入增长率(×)净经营资产销售百分比 (=)基期净经营资产(×)营业收入增长率
2. **第二步：计算内部融资额** 内部融资额(=)预计增加的留存收益+可动用的金融资产 (=)预计营业收入(×)预计营业净利率(×)（1‑预计股利支付率）+可动用的金融资产
3. **第三步：计算外部融资额** 外部融资额(=)融资总需求‑内部融资额

## 2.内含增长率的计算

- **特征**：没有可动用的金融资产，且外部融资额为 0，只靠内部积累所达到的销售增长率
- **计算方法** ①定义法：令外部融资销售增长比为 0，求销售增长率
    
    > 0=净经营资产销售百分比 $-$ 经营负债销售百分比 $-[(1+$ 销售增长率 ）/销售增长率 x 预计营业净利率 $(×)(1-$ 预计股利支付率 ）
    

②三连乘法：

> 内含增长率 $(=)$ 预计营业净利率 $(×)$ 净经营资产周转率 $(×)$ 预计利润留存率 $\div(1-$ 分子 $())$

③简便算法（推荐使用）

> 内含增长率 = ==基期留存收益增加 $\div($ 基期末净经营资产 $-$ 基期留存收益增加 ）== 
> = ==预期留存收益增加 $\div($ 预期期末净经营资产 $-$ 预期留存收益增加 ）==

> 📌小帕提示：在内含增长率下，留存收益增加是净经营资产增加的唯一来源，所以留存收益增加在前，净经营资产在后，不要把公式中参数的前后关系搞错。

## 3.可持续增长率的计算

- **特征**：不发行新股（含不回购股票），不改变经营效率（不改变营业净利率和总资产周转率）和财务政策（不改变权益乘数和利润留存率）时，所能达到的销售增长率

### 假设条件&结论

|分类|假设条件|结论|
|---|---|---|
|经营效率不变|①不发行新股且不回购股票|股本不变，股东权益增长率(=)本年留存收益增加/期初股东权益|
||②营业净利率不变|营业收入增长率(=)净利润增长率|
||③总资产周转率不变|营业收入增长率(=)总资产增长率|
|财务政策不变|④权益乘数不变|总资产增长率(=)股东权益增长率(=)总负债增长率|
||⑤利润留存率不变|净利润增长率(=)股利增长率(=)利润留存增长率|

> ✅结论：若同时满足 5 个假设条件，营业收入增长率(=)可持续增长率(=)总资产增长率(=)总负债增长率(=)股东权益增长率(=)净利润增长率(=)股利增长率(=)利润留存增长率

### 计算方法

计算出发点：可持续增长率(=)股东权益增长率

①简易法（推荐使用）

> 可持续增长率===留存收益增加/期初股东权益==
> ===留存收益增加/(期末股东权益‑留存收益增加==

②根据期初股东权益计算

> 可持续增长率(=)本期净利润(×)本期利润留存率÷期初股东权益 (=)营业净利率(×)期末总资产周转次数(×)期末总资产期初权益乘数(×)利润留存率 
> 💡小帕提示：可持续增长率(=)四连乘（股东权益用期初数，其它时点数都用期末数）

③根据期末股东权益计算

> 可持续增长率(=)营业净利率(×)期末总资产周转次数(×)期末权益乘数(×)本期利润留存率(\div()1‑分子()) (=)期末权益净利率(×)利润留存率(\div()1‑分子()) 💡小帕提示：可持续增长率(=)四连乘/(1‑四连乘())（时点数都用期末数）

### 易错点提示

1. 只有当题目明确说明本年“处于可持续增长状态”，才能使用期初权益公式
2. 无论题目是否说明本年处于可持续增长状态，都可以根据期末权益公式计算当年的可持续增长率
3. 若为管理用财务报表，只需将公式中的“总资产”转换为“净经营资产”

### 内含增长率与可持续增长率的异同点

- **相同点** ①都是销售增长率；②都不增发新股
- **不同点**
- 内含增长率：资本结构可以变动；不可以动用金融资产；外部融资额(=)0
- 可持续增长率：资本结构不变；不可以动用金融资产；外部融资可以增加负债

# 专题二 投资项目资本预算
## 一、主观题考情分析
本专题基本每年都会考一道计算分析题或综合题，非常重要。

命题方向：
（1）新建项目投资决策；
（2）固定资产更新决策；
（3）投资项目折现率的估计；
（4）投资项目敏感分析。

## 二、主观题高频考点
### 【考点1】投资项目折现率的估计
#### 1.使用企业当前加权平均资本成本作为投资项目的资本成本
应同时满足两个条件：（满足等风险假设）
①新项目的经营风险与企业当前资产的平均风险相同
②公司继续采用相同的资本结构为新项目筹资

#### 2.运用可比公司法估计投资项目的资本成本
使用情形：新项目的经营风险与现有资产的平均经营风险不同（不满足等经营风险假设）

|计算步骤|公式|
| ---- | ---- |
|①卸载可比公司财务杠杆，计算β资产|$β_{资产}=β_{权益}/[1+(1-T_{可比})×可比公司净财务杠杆]$|
|②加载项目的财务杠杆，计算β权益|$β_{权益}=β_{资产}×[1+(1-T_{目标})×项目的净财务杠杆]$|
|③根据项目的β权益，利用资本资产定价模型，计算股权资本成本|股权资本成本=无风险利率+$β_{权益}$×市场风险溢价|
|④确定税后债务资本成本|税前债务资本成本 ×（1‑T）|
|⑤确定项目的加权平均资本成本|加权平均资本成本=税后债务资本成本×项目的净负债比重+股权资本成本×项目的权益比重|

> 📌【小帕提示】
> ①若经营风险变化：卸载可比公司财务杠杆，加载目标公司财务杠杆
> ②若资本结构变化：卸载目标公司当前资本结构，加载目标公司目标资本结构

### 【考点2】新建项目投资决策
#### 各阶段增量现金流量
- **建设期**
现金净流量 = −长期资产投资 +（−营运资本垫支）

- **经营期**
营业现金毛流量 = 营业收入‑付现营业费用‑所得税（不建议用这个公式）
       = 税后经营净利润 + 折旧摊销
       = 税后营业收入‑税后付现营业费用+折旧摊销抵税（常用）

> 📌【小帕提示】现金净流量主要是营业现金毛流量的计算，可能会涉及营运资本垫支

现金净流量（即增量现金流量=现金流入增加额‑现金流出增加额）

#### 解题步骤
**第一步：找现金流**
技巧：现金流解题步骤按三个阶段：建设期、经营期和终结点进行总结，但有的时候界限不是很明显，实际做题时不用完全按照这个顺序。

##### （1）生产设备购置
|项目\时点|0|1|……|N|
|---|---|---|---|---|
|设备购置|‑购置安装成本||||
|设备折旧抵税||购置安装成本×(1‑残值率)÷N×T|||
|设备变现收入||||变现收入金额|
|设备变现收益纳税/损失抵税||||‑(变现收入‑账面价值)×T|

> 📌【小帕提示】
> ①特许使用权购置、无形资产购置等需进行折旧摊销的都可参照该类
> ②旧设备的投入也参照该类，而旧设备期初投入的成本就是旧设备变现的机会成本

##### （2）公司原有房产租赁，现停止租赁投入生产，丧失税后租金收入
①如果原本每年租金在当年收取，则现金流量为“‑租金收入×(1‑所得税税率)”

>举例【2018年计算分析题】2018年末公司准备新上一条生产线，经济周期4年。……公司有一栋厂房正好适合新项目使用。该厂房正在对外出租，每年年末收取租金100万元。2018年末租期到期，可续租也可收回自用。

|2018年末|2019年末|2020年末|2021年末|2022年末|
|---|---|---|---|---|---|
|丧失税后租金收入|-100×(1‑25%)=-75|-75|-75|-75|-75|

②如果每年租金在上年末（或本年初）收取，则现金流量“‑租金收入”发生在每个上年末，当年计算租金抵税“+租金收入×所得税税率”；因为上年末的租金是预收账款，本年确认收入时才交税（注意会计的权责发生制）

##### （3）经营类
|项目\时点|0|1|……|N|
|---|---|---|---|---|
|税后营业收入||营业收入 ×(1‑T)|||
|税后付现成本||付现成本 ×(1‑T)|||

①变动成本默认是付现成本，注意题目中的固定成本是否包含折旧摊销
②如题目中出现因当前项目的实施而使企业原有项目收入下降等机会成本应作为决策相关成本补充填列抵减项目

##### （4）营运资本的投入
|项目\时点|0|1|……|N|
|---|---|---|---|---|
|营运资本|‑投入营运资本|||收回营运资本|

历年真题常见考法
①题目直接给出营运资本的金额
②计算增量：==营运资本=增加的经营性流动资产‑增加的经营性流动负债==
③营运资本与营业收入存在函数关系（常考）
A.营运资本=营业收入×营运资本占营业收入的%
B.营运资本===固定数+当年营业收入×%==
C.营运资本需要=年末营运资本‑年初营运资本

> 📌【小帕提示】当年增加的营运资本=当年需要的营运资本‑上年度已有的营运资本，一定不要把当年需要的营运资本当成当年的现金支出量

**第二步：求净现值**
（1）计算折现率
①根据题目给定的项目投资的必要报酬率进行折现
②若题目未给定投资项目必要报酬率，自行计算

（2）计算净现值
①根据第一步找的现金流，计算各个年度的现金净流量
②按折现系数进行折现计算现值
③累加得出净现值

**第三步：**根据题目要求计算现值指数、等额年金、回收期等（链接客观题核心考点第五章相关内容）

**第四步：作出决策**
根据题目要求，以净现值、现值指数、内含报酬率、等额年金等为判断标准，评估项目的可行性或从两个项目中选优

**第五步：敏感性分析**
（1）最大最小法（性价比低，考试时建议放在最后做或直接放弃）
令净现值为0，测算选定变量的临界值，用于评价项目的特有风险

（2）敏感系数法
敏感系数=目标值变动百分比/选定变量变动百分比

# 专题三 企业价值评估
## 一、主观题考情分析
本专题是计算分析题和综合题的常考章节，非常重要。
本专题将会为大家梳理现金流量折现模型的解题技巧，帮助大家在考试中拿到这一部分的分数。

命题方向：
（1）结合管理用财务报表计算企业现金流量→结合资本成本计算各类资本成本→运用现金流量折现模型进行企业价值评估；
（2）运用相对价值评估模型计算股权价值，但相对价值评估模型主要考查客观题，偶尔考查主观题，21年与现金流量折现模型结合考查了综合题。

## 二、主观题高频考点
### 【考点1】现金流量折现模型
#### 三种现金流量折现模型
基本公式：$\text{价值}=\sum_{t=1}^{n}\frac{\text{现金流量}_t}{(1+\text{资本成本})^t}$

##### 未知数1：现金流量的选择
|选择|对应结果|关系|
| ---- | ---- | ---- |
|①股利现金流量|①股权价值|股权现金流量=实体现金流量‑债务现金流量<br>股权价值=实体价值‑净债务价值|
|②股权现金流量|②股权价值||
|③实体自由现金流量|③实体价值||

##### 未知数2：资本成本的选择
（1）计算股权价值时：选择股权资本成本
（2）计算实体价值时：选择加权平均资本成本

##### 解题步骤（通常考核两阶段增长模型）
|步骤|说明|
| ---- | ---- |
|第一步：编制管理用财务报表|主观题核心考点专题一相关内容|
|第二步：资本成本的确定|客观题核心考点第四章相关内容|
|第三步：根据题干给出的上年数据确定基期数据|基期数据中的财务数据和增长率数据题干一般会直接给出，各财务数据的财务比率关系的数据一般需要根据题干要求计算|
|第四步：根据基期财务数据，增长率数据和财务比率关系，确定详细预测期的现金流量，分别折现至评估时点后相加|考试一般是3‑5年；详细预测期是最重要的内容，主要掌握净投资扣除法：<br>$\text{税后经营净利润}= \text{净利润}+\text{税后利息费用}$<br>$\Delta\text{净经营资产}= \Delta\text{股东权益}+\Delta\text{净负债}$<br>$\text{实体现金流量}= \text{股权现金流量}+\text{债务现金流量}$|
|第五步：确定后续期价值|后续期现金流量具有永续增长的特点<br>先利用固定股利增长率模型，将后续期现金流量折现到详细预测期的期末，再复利折现到评估时点（两次折现）|
|最后，折现求企业价值|详细预测期价值+后续期价值，注意资本成本的选择|

>【小帕提示】预计期和后续期的划分方式可能不止一种，只要确保从后续期第一笔现金流，往后看一期的增长率等于永续增长率，不同划分方式都可进行，最终计算结果是一样的。

| 租赁分析的基本模型 | 租赁净现值=租赁的现金流量总现值‑购买（借款购买）的现金流量总现值   其中：折现率=有担保债券的税后利率 |
| 经营租赁（租赁费可以抵税） | （1）经营租赁的现金流量分析   承租人租赁期的现金流量=‑税后租金=‑租金×(1‑所得税税率)      （2）自行购买的现金流量分析   初始点：初始现金流量=‑购置设备支出   营业期：营业现金流量=折旧×所得税税率‑维修费用×(1‑所得税税率)   【小帕提示】若合同约定设备日常维修费用由承租人承担，则设备维修费用是非相关现金流量，无需考虑   终结点：终结点现金流量=变现收入‑相关所得税   【小帕提示】相关所得税的计算方法：   ①相关所得税=（变现收入‑计税基础）×所得税税率   其中：计税基础=固定资产原值‑按税法规定计算的累计折旧，此时的计税基础为固定资产终结点的计税基础   ②变现收入＞计税基础，净收益，纳税，现金流出；反之，净损失，抵税，现金流入   终结点现金流量=变现收入‑收益纳税（+损失抵税） |
| 融资租赁的现金流量分析 | （1）期末所有权转移给承租人   ①租赁期现金流量=‑租金+折旧×所得税税率   ②终结点现金流量=‑支付设备的名义买价+变现收入‑相关所得税   或：终结点现金流量=‑支付设备的名义买价+变现收入‑收益纳税（+损失抵税）   【小帕提示】相关所得税=（变现收入‑计税基础）×所得税税率      （2）期末所有权不转移   ①租赁期现金流量=‑租金+折旧×所得税税率   ②终结点现金流量=‑相关所得税 |
