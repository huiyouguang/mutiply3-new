# 个人所得税：纳税义务人与征税范围考点精讲

## 第一节 纳税义务人与征税范围

### 一、纳税义务人（★）

#### 1. 范围
纳税义务人包括中国居民、个体工商户、==个人独资企业==、合伙企业个人投资者、在中国有所得的外籍人员（包括无国籍人员）和香港、澳门、台湾同胞。

#### 2. 分类
按照**住所和居住时间**两个标准，将纳税人划分为居民个人和非居民个人：

| 类型    | 判定标准                                                         | 纳税义务     |
| ----- | ------------------------------------------------------------ | -------- |
| 居民个人  | （1）在中国境内**有住所**的个人<br>（2）无住所而一个纳税年度在中国境内居住累计满**183天**的个人     | ==全球所得== |
| 非居民个人 | （1）在中国境内**无住所又不居住**的个人<br>（2）无住所而一个纳税年度内在境内居住累计**不满183天**的个人 |==境内所得==|

##### 提示：
① 居住天数判断：在中国境内停留当天满24小时的，计入居住天数；不足24小时的，**不计入**居住天数。
② 住所理解：因户籍、家庭、经济利益关系，在中国境内习惯性居住的个人，住所一般是公民长期生活活动的主要场所。

#### 典例研习·5-1（单项选择题）
德国人尼克在中国境内无住所，2024年7月5日来我国工作，2025年6月30日凌晨1点搭乘飞机返回德国。则下列各项说法正确的是（）。
A. 2024年尼克属于我国居民个人
B. 2025年尼克属于我国居民个人
C. 2024年和2025年尼克均属于我国非居民个人
D. 2024年和2025年尼克均属于我国居民个人

**斯尔解析**：
2025年6月30日当天尼克在境内停留不足24小时，不计入居住天数；2024、2025两个纳税年度内，尼克单年境内居住天数均不满183天，两年均为非居民个人。
**本题答案：C**

======### 二、征税范围（★★）

#### （一）综合所得

##### 1. 工资、薪金所得
（1）定义：个人因**任职或者受雇**取得的工资、薪金、奖金、年终加薪、劳动分红、津贴、补贴及与任职受雇相关的其他所得。

（2）特殊项目划分：====

| 计入工资、薪金所得                                                                                                                                                          | ==不计入工资、薪金所得==                                                                      |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------- |
| ①退休人员再任职取得的收入<br>②公司职工取得的用于购买企业国有股权的劳动分红<br>③企业对营销业绩突出雇员以旅游形式发放的业绩奖励（实物、有价证券等）<br>④出租车归公司所有，驾驶员单车承包/承租营运取得的收入<br>⑤公务用车、通讯制度改革取得的公务用车、通信补贴收入（按月并入当月计税；不按月分摊到所属月份计税） | ①独生子女补贴<br>②托儿补助费<br>③公务员制度未纳入基本工资总额的补贴、津贴差额和家属副食补贴<br>④差旅费津贴、误餐补助（以误餐补助名义发放的补助需计税） |

##### 2. 劳务报酬所得
个人**独立从事非雇佣**的各类劳务取得的所得：
1. （1）营销业绩突出的**非雇员**取得的旅游形式业绩奖励，按劳务报酬计税；
2. （2）不在公司任职受雇的独立董事、监事取得的董事费、监事费，按劳务报酬计税；若同时任职受雇，并入工资薪金计税；
3. （3）保险营销员、证券经纪人取得的佣金收入，属于劳务报酬所得；
4. （4）互联网平台提供营利性服务取得的所得（未做市场主体登记的平台经营者做货物、运输经营的，归经营所得）。

> 解题高手：区分工资薪金&劳务报酬
核心判断：是否存在**任职受雇关系**
- 有任职受雇：从任职单位领报酬 → 工资薪金所得
- 无任职受雇：独立对外提供劳务取酬 → 劳务报酬所得

##### 3. 稿酬所得
个人因作品以图书、报刊形式**出版、发表**取得的所得：
（1）作者去世后，遗作==稿酬按稿酬==所得计税；
（2）未出版发表的翻译、审稿、书画所得，按==劳务报酬==所得计税。

##### 4. 特许权使用费所得
个人提供专利权、商标权、著作权（不含稿酬）、非专利技术等==特许权使用权取得==的所得；
作者拍卖文字作品手稿原件/复印件取得的所得，按==特许权使用费==计税。

#### （二）经营所得
##### 1. 范围
（1）个体工商户、个人独资企业投资人、合伙企业个人合伙人，来自境内注册主体的生产经营所得；经营无关的所得按对应项目计税（如对外投资股息按股息红利计税）；
（2）个人有偿办学、医疗、咨询等服务取得的所得；
（3）对企事业单位承包、承租经营（成果归承包人所有）的所得；
（4）其他生产经营所得：彩票代销所得、个体出租车运营所得、个人独资/合伙律所年度经营所得等。

##### 2. 特殊规定
个人独资企业、合伙企业的个人投资者，用企业资金为本人/家属/相关人员支付与经营无关的消费、财产性支出，==视为利润分配，并入经营所得计税。==

#### （三）利息、股息、红利所得
个人拥有债权、股权取得的利息、股息、红利所得：
（1）除个独、合伙企业外的其他企业投资者，企业为其支付无关消费/财产支出、年末借款未归还且未用于经营的，视为红利分配，按本项目计税；
（2）企业上述支出不得在企业所得税税前扣除。

> 解题高手：购车购房个税项目辨析




| 情形                | 适用应税项目         |
| ----------------- | -------------- |
| 个独/合伙企业投资者及家属购车购房 | ==经营所得==       |
| 其他企业投资者及家属购车购房    | ==利息、股息、红利所得== |
| 为企业普通员工购车购房       | ==工资、薪金所得==    |
====*注：车辆同时用于经营的，可按主管机关标准合理减除部分所得计税*

#### （四）财产租赁所得
个人出租不动产、机器设备、车船及其他财产取得的所得；**财产转租收入**也按本项目计税，由转租人纳税。

#### （五）财产转让所得
个人转让有价证券、股权、合伙份额、不动产、机器设备、车船等财产取得的所得；
企业改组量化资产处理规则：

| 职工取得量化资产情形 | 取得时      | 转让/分红时                      |
| ---------- | -------- | --------------------------- |
| 仅分红、无所有权   | ==不征收==  | ==分红按利息股息红利计税==                 |
| 股份制形式拥有所有权 | ==暂缓征收== | ==转让按财产转让所得计税（收入减除成本、税费后余额计税）== |

#### （六）偶然所得
个人得奖、中奖、中彩及其他偶然性质所得，由发奖方代扣代缴：

（1）股权收购的不竞争款项、担保收入、无偿受赠房屋（免税情形除外）按本项目计税；
（2）房屋赠与免税情形：赠与直系亲属/近亲属、直接赡养义务人、法定/遗嘱继承人；
（3）企业赠送礼品：

|处理|适用情形|
| ---- | ---- |
|按偶然所得征税|年会/宣传活动随机向本单位以外个人赠礼品、额外抽奖获奖所得|
|不征税|价格折扣折让、销售附赠、积分兑换礼品|

### 三、所得来源地的确定（★）
除另有规定，以下所得无论支付地点，均视为来源于中国境内：

|所得类型|境内判定情形|
| ---- | ---- |
|劳务所得|在中国境内提供劳务|
|不动产转让所得|不动产坐落在中国境内|
|其他财产转让所得|在中国境内完成转让|
|财产租赁、特许权使用费所得|财产/特许权在中国境内使用|
|利息股息红利所得|从中国境内单位、个人处取得|

> 解题高手：个人&企业所得来源地对比


|所得类型|个人所得税来源地|企业所得税来源地|
| ---- | ---- | ---- |
|租金、特许权使用费|财产/特许权使用地|负担支付所得的企业所在地|
|动产转让所得|转让行为发生地|转让动产的企业所在地|

## （二）综合所得年度应纳税额的计算

### 1. 计算公式
- **应纳税额** = ==全年应纳税所得额 × 适用税率 - 速算扣除数==
- **全年应纳税所得额** = ==全年综合所得收入额 - 60 000 元 - 专项扣除 - 专项附加扣除 - 依法确定的其他扣除 - 允许扣除的捐赠额==

---

### 2. 收入额的确定
| 综合所得 | 应税收入额的计算规则 |
| :--- | :--- |
| 工资、薪金所得 | ==全额计入== |
| 劳务报酬所得 | ==实际取得的收入 × (1-20%)== |
| 特许权使用费所得 | ==实际取得的收入 × (1-20%)== |
| 稿酬所得 | ==实际取得的收入 × 70% × (1-20%)== |

### 3. 扣除项目
#### （1）专项扣除
包括居民个人按照国家规定的范围和标准缴纳的**基本养老保险、基本医疗保险、失业保险**等社会保险费和**住房公积金**等（即个人实际缴付的**==三险一金==**）。

##### 精佳答疑：为什么企业可以扣除“五险一金”，个人只能扣除“三险一金”？
政策规定，个人缴纳的只有**三险一金**，无须缴纳生育保险和工伤保险。

|  五险一金  | 企业是否缴纳 | 个人是否缴纳 |
| :----: | :----: | :----: |
| 基本养老保险 |        | ==√==  |
| 基本医疗保险 |        | ==√==  |
|  生育保险  | ==√==  | ==×==  |
|  工伤保险  | ==√==  | ==×==  |
|  失业保险  |        | ==√==  |
| 住房公积金  |        | ==√==  |

> 提示：在具体征收时，基本医疗保险和生育保险合并征收。

### 精佳答疑
1. **问题**：如果纳税人在一个纳税年度内同时取得了初级、注会、税务师等多个职业资格证书，可以叠加扣除多个3 600元吗？
   **解答**：不可以。在同一个纳税年度内取得多项资格证书，也只能按照 ==3 600 元== 定额扣除。

2. **问题**：如果夫妻两人在同一个纳税年度内发生的大病医疗支出扣除医保报销后，个人负担的金额都是10万元，在计算可以扣除金额的时候，限额是8万元还是16万元？
   **解答**：大病医疗支出的扣除金额应按规定分别计算扣除额，即分别和限额 ==8 万元== 进行比较。合计可以扣除的金额为 ==16 万元==。

# 一、居民个人取得综合所得（续）
## 3. 依法确定的其他扣除
个人缴付符合国家规定的**企业年金、职业年金**、个人购买符合国家规定的**商业健康保险**、**个人养老金**支出。

| 类型 | 扣除标准 | 详细规定 |
| :--- | :--- | :--- |
| 企业年金、职业年金 | ==工资计税基数的 4%== | 个人缴费部分，在不超过本人缴费工资计税基数的 ==4%== 标准内的部分，暂从个人当期应纳税所得额中扣除 |

## （三）综合所得预扣预缴应纳税额的计算
### 1. 居民个人取得工资、薪金所得预扣预缴的计算
#### （1）计算方法和公式
- **计算方法**：==累计预扣法==（适用综合所得个人所得税税率表（年度表））
- **具体公式**：
  - 累计预扣预缴应纳税所得额 = ==累计收入 - 累计免税收入 - 累计减除费用 - 累计专项扣除 - 累计专项附加扣除 - 累计依法确定的其他扣除==
  - 本期应预扣预缴税额 =（==累计预扣预缴应纳税所得额 × 预扣率 - 速算扣除数）- 累计减免税额 - 累计已预扣预缴税额==

#### （2）累计减除费用的计算
| 情形 | 具体计算方法 |
| :--- | :--- |
| 一般情况 | ==5 000 元 × 当年截至本月在本单位任职受雇月份数== |
| 一个纳税年度内首次取得工资、薪金的居民个人 | ==5 000 元 × 当年截至本月的月份数== |
| 上一完整纳税年度内均在同一单位预扣预缴工资、薪金所得个人所得税，且全年累计工资、薪金收入（含奖金，不扣任何费用）不超过 6 万元的居民个人 | 从1月起直接按 ==6 万元== 计算（即纳税人累计收入不超过6万元的月份，暂不预扣预缴个人所得税） |

> 提示：
> ① 首次取得工资、薪金，指从当年1月至新入职时，未取得工资、薪金所得或未按照累计预扣法预扣预缴连续性劳务报酬所得个人所得税。
> ② 对上一完整纳税年度内每月均在同一单位取得劳务报酬，且已按累计预扣法预扣预缴，全年累计劳务报酬（不扣任何费用）不超过6万元的居民个人，也比照上述第三种情形，累计减除费用自1月起直接按全年6万元计算。

#### （3）累计专项附加扣除的计算
累计专项附加扣除的金额，为该员工在本单位截至当前月份符合政策条件的扣除金额。
> 提示：年度汇算清缴时，专项附加扣除按**满足条件的月份数**扣除，与实际参加工作月份数无关。如1月起满足条件则扣12个月，7月起满足则扣6个月。

##### 精佳答疑
**问题**：对于一个纳税年度内首次取得工资、薪金的居民个人，费用减除按5 000元/月乘以当年截至本月份的累计月份数计算，专项附加扣除是否也应按此方法计算？
**解答**：只有**“费用减除”**按当年截至本月份的累计月份数计算，专项附加扣除无此规定，仍应按照**“在本单位工作的符合条件的月份数”**计算。

### 2. 居民个人取得劳务报酬所得、稿酬所得、特许权使用费所得预扣预缴的计算
#### （1）基本计算方法
- 预扣预缴应纳税所得额（收入额）= 每次取得的收入 - 费用减除
- 劳务报酬所得应预扣预缴税额 = 预扣预缴应纳税所得额 × 预扣率 - 速算扣除数
- 稿酬所得、特许权使用费所得应预扣预缴税额 = 预扣预缴应纳税所得额 × 20%

> 提示：稿酬所得的收入额再减按 ==70%== 计算。

| 特许权使用费所得 | 同劳务报酬所得 | 20% | — |
| 稿酬所得 | 同劳务报酬所得 | 20% | — |

#### （2）按照累计预扣法预扣预缴税款的劳务报酬
适用情形：
1. ① 正在接受全日制学历教育的学生因实习取得的劳务报酬所得。

# 四、财产租赁所得（★★）
## （一）税率
比例税率 ==20%==。但对个人按市场价格出租的居民住房取得的所得，暂减按 ==10%== 的税率征收个人所得税。

## （二）计算公式
1. 每次（月）收入不超过 4 000 元的：
$$\text{应纳税所得额} = \text{每次（月）收入} - \text{准予扣除项目} - \text{修缮费用（800 元为限）} - 800\ \text{元}$$
2. 每次（月）收入超过 4 000 元的：
$$\text{应纳税所得额} = \left[ \text{每次（月）收入} - \text{准予扣除项目} - \text{修缮费用（800 元为限）} \right] × (1-20\%)$$

## （三）准予扣除的项目
| 扣除项目           | 具体规定                                                                          |
| :------------- | :---------------------------------------------------------------------------- |
| 税费             | ==出租财产过程中缴纳的税金和国家能源交通重点建设基金、国家预算调节基金、教育费附加==                                      |
| 转租租金（仅适用于转租情形） | ==向房屋原出租方支付的租金（凭房屋租赁合同和合法支付凭据）==                                                  |
| 修缮费用           | ==由纳税人负担的该出租财产实际发生的修缮费用（能够提供有效、准确凭证），以每次 800 元 为限，一次扣除不完的，准予在下一次继续扣除，直到扣完为止== |
| 费用减除           | ==每次（月）收入不超过 4 000 元的，定额减除费用 800 元；每次（月）收入 4 000 元以上，定率减除 20% 的费用==       |

> 提示：财产租赁所得中税前扣除项目的扣除次序为：税费、向出租方支付的转租租金、修缮费用、费用减除。

### 解题高手
**命题角度1：财产租赁所得个税计算**
- 税率适用：个人出租住房税率 ==10%==，出租非住房税率 ==20%==。
- 扣除项目：是否考虑税费、转租租金、修缮费用看题目信息；无论何种情形，必须扣除费用减除。

**命题角度2：个人出租住房/非住房各税种计算**

| 类型 | 增值税 | 房产税 | 印花税 | 个人所得税 |
| :--- | :--- | :--- | :--- | :--- |
| 个人出租住房 | 3% 征收率减按 ==1.5%== 征税 | 4% | 免税 | 10% |
| 个人出租非住房 | 3% 征收率 | 12% | 1‰ | 20% |

> 提示：
> ① ==自然人一次性收取租金，月租金未达 10 万元的，免征增值税。==
> ② 个人同时享受“六税两费”减半征收优惠。

### 典例研习·5-11
刘某出租住房，月租金 6 500 元，2 月发生修缮费 1 000 元（已取得凭证），不考虑其他税费：
1. 除2、3月外，每月应纳税额：$6\ 500 × (1-20\%) × 10\% = 520$ 元
2. 2月应纳税额：$(6\ 500-800) × (1-20\%) × 10\% = 456$ 元
3. 3月应纳税额：$(6\ 500-200) × (1-20\%) × 10\% = 504$ 元
4. 全年应纳税额：$456 + 504 + 520 × 10 = 6\ 160$ 元

## （四）个人转让股权应纳税额的计算
### 1. 股权转让的征税范围
1. （1）个人出售股权
2. （2）公司回购个人股权
3. （3）首次公开发行新股时，个人股东将持有的股份以公开发行方式向投资者发售
4. （4）个人股权被司法或行政机关强制过户
5. （5）个人以股权对外投资或进行其他非货币性交易、以股权抵偿债务
6. （6）其他股权转移行为

### 2. 计算公式
$$\text{股权转让所得} = \text{股权转让收入} - \text{股权原值} - \text{合理费用}$$

#### （1）股权转让收入

- 税务机关核定股权转让收入的情形：

| 情形               | 具体规定                                                                                                                                                                                                      |
| :--------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 可核定收入的情形         | ==① 申报的股权转让收入明显偏低且无正当理由的<br>② 未按期申报，经责令限期申报仍不申报的<br>③ 无法提供或拒不提供股权转让收入有关资料的<br>④ 其他应核定收入的情形==                                                                                                              |
| 视为明显偏低的情形（四低）    | ==① 申报收入低于股权对应的净资产份额的<br>② 申报收入低于初始投资成本或低于取得股权支付的价款及税费的<br>③ 申报收入低于相同或类似条件下同一企业同一股东/其他股东股权转让收入的<br>④ 申报收入低于相同或类似条件下同类行业企业股权转让收入的<br>⑤ 不具合理性的无偿让渡股权或股份==                                                   |
| 视为有正当理由（无须核定）的情形 | ==① 能出具有效文件，证明被投资企业因国家政策调整，生产经营受到重大影响，导致低价转让股权<br>② 继承或将股权转让给能提供具有法律效力身份关系证明的配偶、父母、子女、祖父母、外祖父母、孙子女、外孙子女、兄弟姐妹以及对转让人承担直接抚养或者赡养义务的抚养人或者赡养人<br>③ 相关法律、政府文件或企业章程规定，并有相关资料充分证明转让价格合理且真实的本企业员工持有的不能对外转让股权的内部转让== |

> 提示：主管税务机关可依次按照净资产核定法、类比法和其他合理方法核定股权转让收入。

#### （4）股权原值的确认
| 股权取得的方式 | 原值的确认规定 |
| :--- | :--- |
| 现金出资 | 实际支付的价款与取得股权直接相关的合理税费之和 |
| 非货币性资产出资 | 投资入股时非货币性资产价格与取得股权直接相关的合理税费之和 |
| 无偿让渡 | 符合继承或特定亲属转让情形的，取得股权发生的合理税费与原持有人的股权原值之和 |
| 被投资企业以资本公积、盈余公积、未分配利润转增股本，已缴纳个人所得税 | 转增额和相关税费之和 |

> 个人多次取得同一被投资企业股权的，转让部分股权时，采用==加权平均法==确定股权原值。

#### （5）纳税人和扣缴义务人
| 维度 | 具体规定 |
| :--- | :--- |
| 纳税人 | 股权转让方 |
| 扣缴义务人 | ① 股权受让方代扣代缴税款<br>② 股权转让协议签订后 ==5 个工作日== 内，将股权转让有关情况报告主管税务机关 |

#### （6）收回转让股权的个人所得税规定
股权转让合同履行完毕、股权已作变更登记且所得已实现的，转让人取得的股权转让收入应缴纳个税；转让结束后，双方解除合同、退回股权的，属于另一次股权转让行为，对前次转让已征收的个税税款不予退回。

3. 同时持有限售股及流通股的，转让时视同先转让限售股，按规定计算个税。

| :--- | :--- |
| 应税所得项目 | 财产转让所得 |

## （七）个人转让债券 / 债权
### 1. 转让债券
应采用==加权平均法==确定其应予减除的财产原值和合理费用：
$$\begin{align}
\text{一次卖出债券应扣除的买价及费用} =& \left( \frac{\text{购进的同一种类债券的买入价和买进过程中缴纳的税费总和}}{\text{购进该类债券数量之和}} \right) × \text{卖出的该类债券的数量} \\
&+ \text{允许扣除的卖出该债券过程中缴纳的税费}
\end{align}$$

### 2. 转让债权
个人通过招标、竞拍或其他方式购置债权后，通过相关程序主张债权而取得的所得，应按“财产转让所得”项目征税。
个人取得打包债权，只处置部分债权的，应纳税所得额确定方式：
（1）以每次处置部分债权的所得，作为一次财产转让所得征税。
（2）收入为个人取得的货币资产和非货币资产的评估价值或市场价值的合计数。
（3）所处置债权成本费用（即财产原值），按当次处置的==债权账面价值占打包债权总账面价值的比例==分配至当次财产转让所得中扣除：
$$\text{当次处置债权成本费用} = \text{个人购置打包债权实际支出} × \frac{\text{当次处置债权账面价值}}{\text{打包债权账面价值}}$$
（4）购买和处置债权过程中发生的拍卖招标手续费、诉讼费、审计评估费以及缴纳的税金等合理税费，==允许扣除==。

# 六、利息、股息、红利所得（★）
## （一）税率
比例税率 ==20%==。

## （二）计算公式
$$\text{应纳税额} = \text{应纳税所得额} × \text{适用税率} = \text{每次收入额} × 20\%$$

## （三）应纳税额的计算
1.  应纳税所得额为取得的收入总额，无允许减除的费用。
2.  个人取得国债利息、国家发行的金融债券利息和储蓄存款利息**免税**。
3.  个人从公开市场取得的上市公司股票的股息、红利所得，适用差别化征免规定：
    - 持股期限超过1年的，**暂免征收**个人所得税。
    - 持股期限在1个月以内（含1个月）的，**全额计入**应纳税所得额。
    - 持股期限在1个月以上至1年（含1年）的，**暂减按50%**计入应纳税所得额。

# 八、公益慈善事业捐赠扣除政策的规定（★）
个人通过境内公益性社会组织、群众团体、县级以上人民政府及其部门等国家机关，向扶贫、济困等公益慈善事业进行捐赠，有限额扣除和据实扣除的规定。**个人直接捐赠，不得扣除**。

## （一）公益性捐赠扣除金额的规定
### 1. 限额扣除的公益性捐赠
1.  个人发生的扶贫、济困等公益捐赠，捐赠额未超过纳税人申报的应纳税所得额 ==30%== 的部分，可从其应纳税所得额中扣除；国务院规定全额税前扣除的，从其规定。
2.  个人捐赠住房作为廉租住房、公租房，符合规定的，捐赠额未超过纳税人申报的应纳税所得额 ==30%== 的部分，可从其应纳税所得额中扣除。
> 提示：在综合所得、经营所得中扣除的，扣除限额分别为当年综合所得、当年经营所得应纳税所得额的30%；在分类所得中扣除的，扣除限额为当月分类所得应纳税所得额的30%。

### 2. 全额据实扣除的公益性捐赠
1.  个人通过非营利性的社会团体和政府部门对下列机构的捐赠：
    - 对红十字事业的捐赠。
    - 对农村义务教育（含各类教育事业）的捐赠。
    - 对老年服务机构的捐赠。
    - 对公益性青少年活动场所的捐赠。
    - 对非关联的科研机构和高等学校用于研发的捐赠。
    - 对其他特定事项的捐赠。
    - 个人对于地震灾区、重大体育赛事等临时性事件的捐赠，也有可全额扣除的规定。
2.  对特定公益组织的捐赠：
    对个人向中华健康快车基金会、宋庆龄基金会、中国扶贫基金会等单位的公益性捐赠，准予在个人所得税税前全额扣除。

### 3. 捐赠支出金额的确定
| 捐赠的资产类型 | 金额的确定 |
| :--- | :--- |
| 货币性资产 | 实际捐赠金额 |
| 股权、房产 | 财产原值 |
| 除股权、房产以外的其他非货币性资产 | 非货币性资产的市场价格 |
> 个人独资企业、合伙企业发生的公益捐赠支出，个人投资者应按分配比例计算归属的捐赠支出，在其经营所得中扣除。

## （二）公益捐赠扣除顺序
居民个人发生的公益捐赠支出可在综合所得、经营所得或分类所得中扣除，自行决定扣除顺序。
1.  **在综合所得中的扣除**：


| 所得项目 | 预扣预缴 | 汇算清缴 |
| :--- | :--- | :--- |
| 工资、薪金所得 | 可以扣除 | 可以扣除 |
| 劳务报酬所得、稿酬所得、特许权使用费所得 | 不得扣除 | 可以扣除 |
    > 提示：个人从两处以上取得工资、薪金所得，选择其中一处扣除，选择后当年不得变更。
2.  **在经营所得中的扣除**：
    - 可选择在预缴税款时扣除，也可选择在汇算清缴时扣除。
    - 经营所得采取核定征收方式的，不得扣除。
3.  **在分类所得中的扣除**：
    可在当月取得的分类所得中扣除。当月分类所得中应扣未扣的可通过以下三种方式追补扣除：
    ① 扣缴义务人已代扣但尚未解缴税款的，居民个人向扣缴义务人提出追补扣除申请，退还已扣税款。
    ② 扣缴义务人已代扣且解缴税款的，居民个人在公益捐赠之日起90日内提请扣缴义务人向税务机关办理更正申报追补扣除。
    ③ 居民个人自行在公益捐赠之日起90日内向主管税务机关办理更正申报追补扣除。

## （三）扣除捐赠支出后个税的计算
1.  **综合所得、经营所得**：
    $$\text{应纳税额} = (\text{应纳税所得额} - \text{允许扣除的捐赠额}) × \text{适用税率} - \text{速算扣除数}$$
2.  **分类所得**：
    $$\text{应纳税额} = (\text{应纳税所得额} - \text{允许扣除的捐赠额}) × \text{适用税率}$$

### 精佳答疑
- **问题1**：公益性捐赠在综合所得中扣除时，是按照减除费用60000元、专项扣除和专项附加扣除之后的金额计算扣除限额，还是减除之前的计算？
  **解答1**：公益性捐赠扣除限额的计算基数是**应纳税所得额**，所以应按照减除费用60000元、专项扣除、专项附加扣除和依法确定的其他扣除之后的应纳税所得额为基础乘以30%，得出扣除限额。
- **问题2**：公益性捐赠在综合所得中扣除时，在不超过全年应纳税所得额30%限额内扣除，应用扣除捐赠前的应纳税所得额找税率表，还是扣除捐赠后的应纳税所得额再找税率表？
  **解答2**：应用**扣除公益捐赠之后的应纳税所得额**再找对应的税率和速算扣除数。

### 典例研习·5-12
陈某2025年每月应发工资11000元，每月“三险一金”1500元，子女教育专项附加扣除2000元。3月捐赠3000元并选择在3月预扣预缴时扣除：
1.  截至2月：
    累计应纳税所得额 = $11000×2 - 5000×2 - 1500×2 - 2000×2 = 5000$ 元
    2月累计应预扣预缴税额 = $5000×3\% = 150$ 元
2.  截至3月：
    累计应纳税所得额 = $11000×3 - 5000×3 - 1500×3 - 2000×3 = 7500$ 元
    公益捐赠扣除限额 = $7500×30\% = 2250$ 元（<3000元，故允许扣除2250元）
    3月预扣预缴应纳税额 = $(7500 - 2250)×3\% - 150 = 7.5$ 元

## （四）其他征管规定
1.  公益性社会组织、国家机关在接受个人捐赠时，应按规定开具捐赠票据。个人不能及时取得捐赠票据的，暂凭银行支付凭证扣除，并在捐赠之日起90日内补充提供捐赠票据。
2.  机关、企事业单位统一组织员工开展公益捐赠的，纳税人可凭汇总开具的捐赠票据和员工明细单扣除。

### 解题高手：捐赠支出在三税中的处理对比
| 税种 | 扣除规定 | 提示 |
| :--- | :--- | :--- |
| 增值税 | （1）单位和个体工商户捐赠货物：视同应税交易。<br>（2）无偿转让无形资产、不动产或者金融商品：视同应税交易 | — |
| 企业所得税 | 公益性捐赠限额扣除，不超过利润总额12%的部分准予扣除；超过部分，结转3年扣除 | （1）在企业所得税和个人所得税中，直接捐赠均不得税前扣除。<br>（2）限额扣除情形下，企业超出部分可结转扣除，个人超出部分不得结转扣除 |
| 个人所得税 | （1）据实扣除：通过特定途径对教育事业、红十字事业等的捐赠。<br>（2）其他公益性捐赠限额扣除：不超过应纳税所得额的30%，超过部分不得结转 | — |

# 九、应纳税所得额计算中的其他规定
1.  **外币收入的折算**：所得为外币的，按照纳税申报或者扣缴申报的上一月最后一日人民币汇率的中间价，折合成人民币。
2.  **两人取得同一项所得**：两个以上的人取得同一项目收入的，应当对每个人取得的收入分别计算纳税。
3.  **中介费的扣除**：对个人从事技术转让、提供劳务等过程中所支付的中介费，如能提供有效、合法凭证的，允许从其所得中扣除。

# 第三节 税收优惠
## 一、免征个人所得税的项目（★）
按7大类归类记忆：
### （一）津贴补助、社保待遇类

# 第四节 应纳税额计算中特殊问题的处理
## 一、居民个人全年一次性奖金特殊规定（★）
2027.12.31前可二选一：
1. 不并入综合所得：奖金÷12找月度税率表，**单独计税**：
$\text{应纳税额}=\text{全年一次性奖金收入}×\text{适用税率}-\text{速算扣除数}$
2. 并入当月综合所得计税。
补充规则：一个纳税年度只能用一次单独计税；半年奖、季度奖等其他奖金必须并入当月工薪计税。

## 二、与任职、受雇、退休有关所得的特殊规定（★）
### （一）股权激励个税规则
#### 1. 四类股权激励计税基础规则
|类型|应纳税所得额确定|计税方式（2027.12.31前）|
| ---- | ---- | ---- |
|股票期权|授予时不征税；行权所得=（行权市价-行权价）×数量；行权前转让按工薪所得征税|不并入综合所得，全额单独按年度综合税率表计税；一年多次行权需合并计税|
|限制性股票|解禁时计税：所得按解禁份额对应差价和出资额分摊计算|同上|
|股权奖励|获得时按公允市价确认工薪所得|同上|
|股票增值权|兑现时按（行权日-授予日）价差确认工薪所得|同上|
> 行权后再转让股票：境内上市股票转让所得免税，境外正常征税；持股分红按股息红利所得计税。

**答疑区分**：限制性股票是员工激励限售股；限售股多为IPO/股改形成的老股，二者来源、规则不同。

#### 2. 递延纳税政策
|维度|上市公司|非上市公司|
| ---- | ---- | ---- |
|适用情形|符合条件的四类股权激励，备案后可递延|同左|
|递延时限|行权/解禁起不超36个月分期缴纳，离职需提前结清|取得时暂不纳税，递延至股权转让时纳税|
|计税方法|行权时按工薪所得规则算税|转让时按财产转让所得计税|

#### 3. 科技成果转化激励优惠
- 高新技术企业股权奖励：不超5个公历年度分期缴纳；后续套现优先缴税。
- 科研/高校股权奖励：取得时暂不征税，转让时财产原值为0、按财产转让所得计税；分红按股息红利计税。
- 科研/高校现金奖励：可减按50%计入当月工薪计税。

### （二）解除劳动合同经济补偿金
|情形|计税规则|
| ---- | ---- |
|企业破产职工安置费|全额免征|
|个人解除合同一次性补偿≤当地上年职工平均工资3倍|免征|
|超过3倍的部分|不并入综合所得，单独按综合所得年度税率表计税（可扣除已缴社保公积金）|

### （三）提前退休补贴
一次性补贴按**剩余法定工作年限平均分摊**，按月额度找税率单独计税，公式：
$$\text{应纳税额}=\left[\left(\frac{\text{一次性补贴}}{\text{剩余年限}}-60000\right)×\text{税率}-\text{速扣数}\right]×\text{剩余年限}$$
> 答疑：当年正常工薪按累计预扣法计税，提前退休补贴单独分摊计税，二者互不干扰。

### （四）内部退养收入
1. 办理内退取得的月度工薪：按==工薪所得==正常计税；
2. 内退一次性收入：分摊至内退到退休的剩余月份，和当月工薪合并找税率计税；
3. 内退期间再就业工薪：需和原单位当月收入合并自行申报补税。

## （二）适用累计预扣法的劳务报酬所得


### 1. 保险营销员/证券经纪人佣金收入
- 性质：劳务报酬所得，按累计预扣法计税。
- 核心公式：
  1. 收入额 = ==不含增值税收入 × (1−20%)==
  2. 展业成本 =  == 收入额 × 25%==
  3. 累计预扣预缴应纳税所得额 = 收入额×(1−25%) − 累计减除费用（5000元/月×从业月数） − 累计其他扣除
- 提示：预扣预缴时**不扣除**专项扣除/专项附加扣除；汇算清缴时并入综合所得。

### 2. 互联网平台从业人员劳务报酬所得
- 按累计预扣法计税，累计费用按**累计收入×20%**计算，累计减除费用按5000元/月×连续取得收入月份数计算。

## （三）重点群体和退役士兵个税规定
1. **自主择业军队转业干部/随军家属**：从事个体经营的，自领取税务登记证之日起**3年内免征个税**。
2. **自主就业退役士兵**：==从事个体经营的，3年内按每户每年20000元为限额依次扣减增值税、城市维护建设税、教育费附加、地方教育附加和个税，限额最高可上浮20%。==
3. **重点群体创业**：==脱贫人口/持《就业创业证》人员从事个体经营的，3年内按每户每年20000元为限额依次扣减相关税费，限额最高可上浮20%。==

# 第五节 境外所得已纳税额的扣除
## 一、境外所得的界定（★）
以下所得为==来源于中国境外的所得==：
1. 因任职、受雇、履约等在中国境外提供劳务取得的所得。
2. 在中国境外从事生产、经营活动而取得的与生产、经营活动相关的所得。
3. 许可各种特许权在中国境外使用而取得的所得。
4. 将财产出租给承租人在中国境外使用而取得的所得。
5. 从境外企业、其他组织以及非居民个人取得的==利息、股息、红利所得==。
6. 转让中国境外的不动产、转让对中国境外企业及其他组织投资形成的股票/股权/其他权益性资产（该权益价值50%以上由境内不动产构成的除外），或在中国境外转让其他财产取得的所得。
7. 中国境外企业、其他组织以及非居民个人支付且负担的==偶然所得==。
8. 中国境外企业以及其他组织支付且负担的==稿酬所得==。
9. 其他规定情形。

## 二、基本抵免规则（★）
居民个人从境外取得的所得，可从应纳税额中==抵免已在境外缴纳的个人所得税税额==，但抵免额不得超过该境外所得依我国税法计算的==应纳税额==。

|项目|具体规定|
|----|----|
|**可抵免的境外所得税税额**|依照该国（地区）法律应当缴纳且==实际已经缴纳==的所得税税额|
|**抵免限额**|境外所得依我国税法计算的应纳税额；<br>一国（地区）抵免限额 = 该国综合所得抵免限额 + 经营所得抵免限额 + 其他分类所得抵免限额|
|**实际抵免处理**|① 境外实缴税额 < 该国抵免限额：在中国==补缴差额税款==；<br>② 境外实缴税额 > 该国抵免限额：以限额为抵免额，==超过部分不得在本年抵免，可在以后5个纳税年度内结转抵免==|

## 三、来源于某一国家（地区）抵免限额的计算方法（★）
|类型|抵免限额计算方法|
|----|----|
|**综合所得的抵免限额（A）**|综合所得抵免限额 = 境内外合并综合所得应纳税额 × 该国综合所得收入额 ÷ ==境内外合并综合所得收入额合计==|
|**经营所得的抵免限额（B）**|经营所得抵免限额 = 境内外合并经营所得应纳税额 × 该国经营所得应纳税所得额 ÷ ==境内外合并经营所得应纳税所得额==|
|**其他分类所得的抵免限额（C）**|其他分类所得抵免限额 = 该国其他分类所得==单独计算的应纳税额==（无须合并）|
|**来源于某一国全部所得的抵免限额**|==A + B + C==|

### 典例研习·5-17 解析
1. **境内外合并综合所得计算**
    - 境内外合并收入额 = 120000 + 50000×(1−20%) = 160000 元
    - 境内外合并应纳税额 = (160000 − 60000 − 12000)×10% − 2520 = 6280 元
2. **甲国综合所得抵免限额**
    - 甲国抵免限额 = 6280 × [50000×(1−20%) ÷ 160000] = ==1570 元==
3. **抵免处理**
    - 甲国实缴税额 10000 元 > 抵免限额 1570 元，本年可抵免 ==1570 元==，剩余 ==8430 元==可结转以后5年抵免。

## 五、其他规定
### 不得抵免的境外已纳税额
1. 按境外税法属于==错缴/错征==的税额；
2. 按税收协定规定==不应征收==的税额；
3. 因少缴/迟缴境外所得税而追加的==利息、滞纳金或罚款==；
4. 从境外征税主体得到==实际返还或补偿==的税额；
5. 按我国法律已==免税==的境外所得负担的税额。

### 境外所得纳税年度判定
境外纳税年度最后一日所在的公历年度，为该境外所得对应的我国纳税年度。

### 境外所得纳税申报
- **申报时间**：取得所得的==次年3月1日至6月30日==。
- **申报地点**：① 中国境内任职受雇单位所在地；② 无任职受雇单位：户籍所在地/经常居住地；③ 扣缴义务人代办：扣缴义务人所在地。

### 未及时享受抵免的处理
可追溯至该境外所得所属纳税年度抵免，但追溯年度==不得超过5年==。

### 外币折算
1. 预缴时：按办理纳税申报==上一月最后一日==人民币汇率中间价折算；
2. 汇算清缴时：按==上一纳税年度最后一日==人民币汇率中间价折算（预缴已折算的不再重算）。

# 第六节 无住所个人的个人所得税政策
## （一）无住所个人所得来源地的判定
1. 无住所个人取得来源于境内的工资薪金，需判断在我国==境内实际工作天数==（含境内实际工作期间的公休假、假期和培训天数）；境内停留当天不足24小时的，按==半天==计入境内工作天数（与判断居民身份的居住天数规则不同）。
2. 同时在境内、境外工作的，按当期境内、境外工作天数占当期公历天数的比例，计算来源于境内、境外的工资薪金所得收入额。

## （二）无住所个人工资、薪金所得收入额的计算（不考虑税收协定）
|纳税人|境内累计居住时间|计税规定和公式|
|----|----|----|
|**非居民个人**|累计居住不超过==90天==|① 仅就境内工作期间、境内雇主支付的部分缴税；<br>② 当月收入额 = 当月境内外工资总额 × 当月境内支付工资比例 × 当月在境内工作时间比例|
||累计居住超过==90天但不满183天==|① 就其在境内工作期间的工资薪金所得缴税；<br>② 当月收入额 = 当月境内外工资总额 × 当月在境内工作时间比例|
|**居民个人**|累计居住满==183天==但连续不满==6年==|① 除境外工作期间且由境外雇主支付的部分外，其余均应缴税；<br>② 当月收入额 = 当月境内外工资总额 × (1 − 当月由境外支付工资比例 × 当月在境外工作时间比例)|
||累计居住满183天的年度连续满==6年==|境内外取得的全部工资薪金所得均应缴税|

|纳税人划分|来源于境内所得（境内工作期间）|来源于境外所得（境外工作期间）|
|----|----|----|
||境内支付|境外支付|境内支付|境外支付|
|非居民个人（≤90天/协定183天）|征税|==免税==|不征税|不征税|
|非居民个人（>90天<183天）|征税|征税|不征税|不征税|
|居民个人（满183天<6年）|征税|征税|不征税|==免税==|
|居民个人（满183天连续6年）|征税|征税|征税|征税|

### 典例研习·5-18 解析
德国人尼克在境内累计居住未超90天，仅就==境内工作期间、境内雇主支付的部分==缴税：
- 11月整月在境内工作，中方支付工资2万元 → 应税收入额==2万元==；
- 12月未在境内工作 → 无须纳税；
- 合计应税收入额为==2万元==。

## （三）无住所个人为高管（董事、监事、高层管理）的情形
高管取得由==境内企业支付==的工资薪金（含奖金、股权激励），==均视为来源于境内的所得==：
1. 境内累计居住≤90天：境内雇主支付的部分全额缴税；
2. 境内累计居住>90天<183天：当月收入额 = 当月境内外工资总额 × (1 − 当月境外支付工资比例 × 当月境外工作时间比例)；
3. 若为居民个人：计税方法与其他无住所居民个人一致。

## 三、综合所得汇算清缴（★）
### （一）需要办理汇算清缴的情形
1. 已预缴税额 > 年度应纳税额且==申请退税==的；
2. 纳税年度内综合所得收入 > ==12万元==且需要补税金额 > ==400元==的；
3. 因适用所得项目错误、扣缴义务人未依法履行扣缴义务等，造成纳税年度内少申报或未申报综合所得的。

### （二）无须办理汇算清缴的情形
1. 年度汇算需补税但综合所得收入 ≤ ==12万元==的；
2. 年度汇算需补税金额 ≤ ==400元==的；
3. 已预缴税额与年度应纳税额一致的；
4. 符合年度汇算退税条件但不申请退税的。

### （三）办理方式
1. 自行办理；
2. 通过任职受雇单位（含按累计预扣法预扣预缴劳务报酬所得的单位）代为办理；
3. 委托涉税专业服务机构或其他单位及个人办理。

### （四）办理渠道
- 个人所得税App、自然人电子税务局网站、邮寄、办税服务厅。

### （五）资料留存
纳税人、代办汇算的单位，需将专项附加扣除、税收优惠材料等汇算相关资料，自年度汇算期结束之日起==留存5年==。

### （六）汇算服务
- 汇算初期提供预约办理服务；
- 符合退税条件且生活负担较重的纳税人，提供==优先退税==服务；
- 特殊人群可申请个性化便民服务；
- 残疾、孤老人员和烈属取得综合所得办理汇算清缴，汇算清缴地与预扣预缴地规定不一致的，按==孰高值==确定减免税额。

## 四、个人所得税反避税规定
### （一）税务机关有权进行纳税调整的情形
1. 个人与其关联方之间的业务往来==不符合独立交易原则==而减少本人或其关联方应纳税额，且无正当理由；
2. 居民个人控制的，或居民个人和居民企业共同控制的设立在==实际税负明显偏低==的国家（地区）的企业，无合理经营需要，对应归属于居民个人的利润不作分配或减少分配；
3. 个人实施其他==不具有合理商业目的==的安排而获取不当税收利益。

### （二）补税及加征利息
1. 税务机关作出纳税调整，需要补征税款的，应当补征税款，并依法==加收利息==；
2. 利息按税款所属纳税申报期最后一日央行公布的与补税期间同期的人民币贷款基准利率计算，自税款纳税申报期满次日起至补缴税款期限届满之日止按日加征；纳税人在补缴期限届满前补缴的，利息加收至补缴税款之日。
