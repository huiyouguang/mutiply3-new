# 注会审计 · 易错编号条目背诵清单（你没选对的）

> 来源：错题目录下全部文件中的 `(1)(2)(3)`… 编号案例/简答题。
> 已**剔除你判断正确**的条目，仅保留「你的答案 ❌ → 标准答案 ✅」需要背诵的。
> 每条附「必背」一句，建议用 `<u>下划线</u>` 句反复默背。

## 一、资产减值与会计估计

1. **金考典·(1) 投资性房地产减值**：管理层作会计估计，CPA 检查了方法/假设/数据。
   - 我的答案 ❌：不恰当，还应评价减值金额完整性。
   - 标准答案 ✅：不恰当，还应评价管理层是否已就**估计不确定性作出披露**。
   - 必背：评价会计估计 = 方法 + 假设 + 不确定性 + **披露**。

2. **金考典·(2) 商誉减值拒绝额外披露**：关键假设高度不确定，管理层拒绝额外披露。
   - 我的答案 ❌：不恰当，应评价假设合理性。
   - 标准答案 ✅：不恰当，应评价管理层未作出额外披露**是否构成重大错报**。
   - 必背：同行业标准**不能替代**职业判断，须独立评价披露充分性。

3. **金考典·(3) 利用外部专家工作**：已评价胜任能力、专业素质、**客观性**。
   - 我的答案 ❌：不恰当，还应评价独立性。
   - 标准答案 ✅：**恰当**（客观性已含独立性，无需重复）。
   - 必背：客观性 ⊇ 独立性，提到"评价客观性"即视为已满足。

4. **金考典·(4) 上期保留事项本期处置资产**：上期未提减值发保留，本期处置后发无保留。
   - 我的答案 ❌：恰当。
   - 标准答案 ✅：不恰当，该事项**对本期仍有重大影响**，应延续保留意见。
   - 必背：上期保留未解决 + 影响本期 → 不得转无保留。

5. **金考典·(5) 管理层未识别减值**：CPA 验证后未发现减值，未再了解相关控制。
   - 我的答案 ❌：不恰当，仍应了解控制。
   - 标准答案 ✅：**恰当**（控制可能未运行/不存在）。
   - 必背：控制本身未运行 → 可不再了解。

6. **BT19年卷·(1) 商誉减值利用专家故不须了解内控**：认为与审计无关。
   - 我的答案 ❌：恰当。
   - 标准答案 ✅：不恰当，商誉减值影响财报，**应当了解**相关内控。
   - 必背：与审计相关的内控都要了解，利用专家不豁免。

7. **第三套卷·(1) 会计估计差异不重大即合理**：将本期跌价准备与上年实际损失比，无差异即认可。
   - 我的答案 ❌：恰当。
   - 标准答案 ✅：不恰当，**差异不必然表明错报**；复核上期结果属风险评估，不能据此认可本期。
   - 必背：会计估计结果 ≠ 已确认金额 → 不一定错报。

8. **第三套卷·(2) 经营无变化仅分析程序追溯复核**：
   - 我的答案 ❌：恰当。
   - 标准答案 ✅：不恰当，**固有风险较高时**须更详细追溯复核。
   - 必背：固有风险高 → 仅分析程序不足以复核。

9. **东奥最后六道·(1) 未决诉讼结案调以前数据**：判决后调 2025 并披露前期差错更正。
   - 我的答案 ❌：恰当。
   - 标准答案 ✅：不恰当，**差异不必然错报，无须前期差错更正**。
   - 必背：会计估计结果与已确认金额差异 ≠ 必然错报。

10. **东奥最后六道·(2) 经营无变化分析程序复核**：
    - 我的答案 ❌：恰当。
    - 标准答案 ✅：不恰当，固有风险高须更详细追溯复核。

## 二、质量管理 / 独立性 / 商业关系

11. **金考典·质量(2) 审计系统服务器架香港**：主北京备香港。
    - 我的答案 ❌：恰当。
    - 标准答案 ✅：**违反**，服务器应架设在**境内**。
    - 必背：审计作业系统服务器（含备用）不得设在境外。

12. **金考典·质量(4) 考评不合格两年后恢复资格**：
    - 我的答案 ❌：恰当。
    - 标准答案 ✅：**违反**，须以**执业质量全面提升**为恢复条件。
    - 必背：恢复资格看质量改善，不看固定期限。

13. **金考典·质量(5) 复核人时间不足仍继续履行**：
    - 我的答案 ❌：不恰当（表述偏）。
    - 标准答案 ✅：**违反，应立即停止**实施项目质量复核。
    - 必背：时间不足 → 立即停止，非"不得履行"。

14. **金考典·独立性(5) 退休返聘后任子公司独董**：D 注会退休返聘为顾问。
    - 我的答案 ❌：恰当。
    - 标准答案 ✅：**违反**，返聘构成与事务所**保持关联**，不得加入关联实体。
    - 必背：返聘 = 仍关联 → 不得任审计客户关联实体董事。

15. **金考典·独立性(6) 姐妹实体法律咨询**：XYZ 为戊公司（甲公司姐妹实体）提供咨询。
    - 我的答案 ❌：不恰当。
    - 标准答案 ✅：**不违反**（非审计客户关联实体）。
    - 必背：姐妹实体通常不属审计客户关联实体。

16. **第三套卷·独立性(5) 公众利益实体计算递延所得税**：XYZ 长期为丙公司（不重要的子公司）提供递延所得税计算。
    - 我的答案 ❌：—
    - 标准答案 ✅：**违反**，公众利益实体审计客户不得提供计算递延所得税服务。
    - 必背：公众利益实体 = 不得提供递延所得税计算。

17. **第三套卷·独立性(6) 合伙人推销非鉴证服务提成**：
    - 我的答案 ❌：—
    - 标准答案 ✅：**违反**，关键审计合伙人薪酬不得与推销非鉴证服务收入直接挂钩。
    - 必背：非鉴证服务奖金不得与关键审计合伙人薪酬挂钩。

18. **东奥最后六道·商业(2) 联合服务团队**：与 XYZ 组联合团队推广一揽子服务。
    - 我的答案 ❌：违反（表述偏）。
    - 标准答案 ✅：**违反，禁止的商业关系**（自身利益/外在压力）。
    - 必背：共同开办/联合推广 = 禁止的商业关系。

19. **东奥最后六道·商业(6) 诉讼支持服务**：XYZ 提供重大影响的诉讼支持。
    - 我的答案 ❌：违反（表述偏）。
    - 标准答案 ✅：**违反**，网络所提供诉讼支持 → 自我评价/推介代理不利。
    - 必背：向审计客户提供诉讼支持 = 自我评价/推介代理。

20. **东奥最后六道·质量(5) 上市实体检查周期**：上市实体检查周期两年、其他四年。
    - 我的答案 ❌：不恰当。
    - 标准答案 ✅：**不违反**，上市实体检查周期**不得超过 3 年**，每年至少选一项。
    - 必背：上市实体项目质量检查周期 ≤ 3 年。

## 三、审计抽样 / 货币资金

21. **金考典·抽样(1) 偏差率 3.4%<3.5% 认为有效**：
    - 我的答案 ❌：不恰当（理由偏）。
    - 标准答案 ✅：不恰当，**两者很接近，抽样风险很高，总体不可接受**。
    - 必背：偏差率接近可容忍 → 风险高，不能直接认可。

22. **金考典·抽样(3) 分层抽样合计推断总体**：两层错报 5 万+10 万直接加总推断。
    - 我的答案 ❌：不恰当（理由偏）。
    - 标准答案 ✅：不恰当，**应对每层分别推断错报**，再汇总。
    - 必背：分层须分别推断，再汇总。

23. **金考典·抽样(4) 比率法算错报**：样本账面 1500 万、错报 150 万、总体 12000 万，算 1500 万。
    - 我的答案 ❌：不恰当（误称货币单元抽样）。
    - 标准答案 ✅：不恰当，比率法应为 **1200 万**（150÷1500×12000）。
    - 必背：比率法 = 样本错报÷样本账面×总体账面。

24. **金考典·货币资金(1) 核对遗漏摘要**：核对日期/金额/方向/收付款单位。
    - 我的答案 ❌：恰当。
    - 标准答案 ✅：不恰当，还应核对**摘要**。
    - 必背：银企对账核对内容含摘要。

25. **金考典·货币资金(2) 亲自寄发询证函**：按公示地址亲自寄发。
    - 我的答案 ❌：恰当。
    - 标准答案 ✅：不恰当，应**安排专门部门/岗位集中发函**。
    - 必背：集中发函是标准要求。

26. **金考典·货币资金(3) 异常资金流一收一付**：检查日记账与划转资料即认可。
    - 我的答案 ❌：不恰当（理由偏"舞弊"）。
    - 标准答案 ✅：不恰当，应关注**资金流转的商业理由**是否合理。
    - 必背：异常资金流 → 关注商业理由。

27. **金考典·货币资金(4) 质押定期存款**：函证+合同+存单复印件即认可。
    - 我的答案 ❌：不恰当（理由偏"商业理由"）。
    - 标准答案 ✅：不恰当，应关注**质押借款有无入账**。
    - 必背：质押借款核心是"是否入账"（负债完整性）。

28. **金考典·货币资金(5) 分析程序差异比实际执行重要性**：差异低于实际执行重要性即不调查。
    - 我的答案 ❌：不恰当（理由偏）。
    - 标准答案 ✅：不恰当，应与**可接受差异额**比较。
    - 必背：分析程序比较对象是"可接受差异额"，非实际执行重要性。

## 四、内部控制审计

29. **金考典·内控(1) 企业层面控制不精确未测试**：
    - 我的答案 ❌：不恰当（应"了解"）。
    - 标准答案 ✅：不恰当，应**测试对有效性结论有重要影响**的企业层面控制。
    - 必背：企业层面控制须"测试"非仅"了解"。

30. **金考典·内控(2) 以银行存款余额调节表为总体**：
    - 我的答案 ❌：不恰当（应以银行存款为总体）。
    - 标准答案 ✅：**恰当**（总体 = 所有调节表）。
    - 必背：测"调节表"→ 总体为调节表，非银行存款余额。

31. **金考典·内控(3) 补偿性控制有效识别一般缺陷**：
    - 我的答案 ❌：不恰当（应评价重大缺陷）。
    - 标准答案 ✅：**恰当**（有效且精确可抵消）。
    - 必背：补偿性控制有效且精确 → 可降为一般缺陷。

32. **金考典·内控(4) 仅测变更后不依赖前后**：
    - 我的答案 ❌：不恰当（应测前后）。
    - 标准答案 ✅：**恰当**（不依赖则无需测）。
    - 必背：不依赖控制 → 无需测试；变更后测即可。

33. **金考典·内控(5) 非财务报告重要缺陷仅与管理层书面沟通**：
    - 我的答案 ❌：未答/错。
    - 标准答案 ✅：不恰当，应以**书面形式与治理层和管理层双方**沟通。
    - 必背：重要/重大缺陷须书面与双方沟通。

34. **第三套卷·内控(1) 财报内控重大缺陷发保留意见**：
    - 我的答案 ❌：不恰当（认为发保留）。
    - 标准答案 ✅：不恰当，应发表**否定意见**（内控审计无保留意见）。
    - 必背：内控审计对财报内控重大缺陷 = 否定意见。

35. **第三套卷·内控(4) 新控制未运行足够长**：基准日前整改但新控制未运行足够长。
    - 我的答案 ❌：存在重大缺陷。
    - 标准答案 ✅：**恰当**（应考虑运行足够长时间后评价）。
    - 必背：新控制未运行足够长 → 基准日无重大缺陷（恰当）。

36. **第三套卷·内控(5) 非财务报告重大缺陷加强调事项段**：
    - 我的答案 ❌：恰当。
    - 标准答案 ✅：不恰当，应在**非财务报告内控重大缺陷描述段**说明。
    - 必背：非财报重大缺陷 → 描述段，非强调段。

## 五、集团 / 底稿 / 书面声明 / 审计报告 / 期后

37. **BT19年卷·集团参与进一步审计程序**：识别出导致集团重大错报的特别风险。
    - 我的答案 ❌：应当参与进一步审计程序。
    - 标准答案 ✅：应当**评价**针对特别风险拟实施进一步审计程序的恰当性。
    - 必背：集团项目组先"评价"恰当性，非强制参与。

38. **东奥最后六道·集团参与(15)**：同 37 情形。
    - 我的答案 ❌：应当参与。
    - 标准答案 ✅：评价恰当性（同 37）。

39. **东奥最后六道·底稿(4) 归档期检查重大事项概要**：
    - 我的答案 ❌：恰当。
    - 标准答案 ✅：不恰当，检查重大事项应在**出具审计报告前**完成。
    - 必背：重大事项检查须在出具报告前。

40. **东奥最后六道·银行完整性从日记账选样本**：为测入账完整性从日记账选样本对账单。
    - 我的答案 ❌：恰当。
    - 标准答案 ✅：不恰当，应**从银行对账单选取样本**与日记账核对。
    - 必背：测完整性 → 从对账单（外部）选样本。

41. **第三套卷·审计报告(2) 无法表示意见仍沟通关键审计事项**：
    - 我的答案 ❌：恰当。
    - 标准答案 ✅：不恰当，**无法表示意见不得沟通**关键审计事项（除非法规要求）。
    - 必背：无法表示意见 → 不沟通关键审计事项。

42. **第三套卷·审计报告(3) 关键审计事项描述原始信息**：丙公司在附注未披露，CPA 在关键事项段补充。
    - 我的答案 ❌：恰当。
    - 标准答案 ✅：不恰当，**不得描述原始信息/不能替代管理层披露**。
    - 必背：关键审计事项不能替代管理层披露。

43. **第三套卷·审计报告(4) 上期保留对本期无影响**：前任保留事项对本期数据无影响。
    - 我的答案 ❌：恰当（拟无保留）。
    - 标准答案 ✅：不恰当，对**本期数据和对应数据可比性仍有影响**，应非无保留。
    - 必背：前期保留影响本期可比性 → 仍非无保留。

44. **第三套卷·审计报告(5) 其他信息部分说明无事项**：保留意见报告其他信息部分说明无任何需报告事项。
    - 我的答案 ❌：恰当。
    - 标准答案 ✅：不恰当，须说明**无法判断**与导致保留意见事项相关的其他信息是否存在重大错报。
    - 必背：非无保留意见 → 其他信息部分须说明"无法判断"。

45. **东奥最后六道·书面声明(1)/(2)**：书面声明可作意见基础/减轻责任。
    - 我的答案 ❌：可作为基础/减轻责任。
    - 标准答案 ✅：**本身不提供充分适当证据，不能作基础，也不能减轻责任**。
    - 必背：书面声明不减轻责任、不单独作证据。

## 六、存货监盘 / 控制测试 / 错报评价 / 函证

46. **第一套卷·存货(1) 监盘前检查标签**：次日取标签检查连续编号。
    - 我的答案 ❌：恰当。
    - 标准答案 ✅：不恰当，应在**监盘前**确定标签连续编号，盘点结束前将汇总表与标签核对。
    - 必背：标签连续编号在监盘前查，汇总表与标签在结束前核对。

47. **第一套卷·存货(3) 抽盘方向**：从记录追查至实物。
    - 我的答案 ❌：恰当。
    - 标准答案 ✅：不恰当，从记录追查实物**无法应对完整性**；应从实物追查记录。
    - 必背：实物→记录 = 完整性；记录→实物 = 准确性。

48. **第一套卷·存货(4) 洪水替代程序**：重要异地仓无法监盘，仅替代。
    - 我的答案 ❌：恰当。
    - 标准答案 ✅：不恰当，应**另择日期监盘** + 对间隔期交易实施程序。
    - 必背：监盘不可行 → 另择日期 + 间隔期程序。

49. **第一套卷·存货(5) 第三方仓储单**：第三方存货检查仓储单即认可。
    - 我的答案 ❌：恰当。
    - 标准答案 ✅：不恰当，还应实施进一步审计程序。

50. **第一套卷·共享(1) 穿行测试确定执行**：选 2 家分公司穿行测试评价设计并确定执行。

## 一、从你自己的笔记里"挖"出的习惯陷阱（最该注意）

这些是你亲笔写的自评，是真实的丢分模式：

1. **"又是知道还选的情况"**（审计报告、持续经营、治理层沟通）
   - 你其实会，但被"应当 / 根据评估结果确定是否"这类措辞带偏。
   - **对策**：看到选项里出现"应当"，先默认它可能是正确答案，反向表述（"根据评估确定"）往往是错的。

2. **"背错表了"**（独立性三大重灾）
   - 公众利益实体不得提供**计算递延所得税**；关键审计合伙人薪酬不得与**非鉴证服务收入**挂钩；共同开办/联合推广 = **禁止的商业关系**。
   - **对策**：把这三句做成单独闪卡，考前必看。

3. **"明明勾选 D 对了，还选 C" / "这题明明判断 C 错误了，还选 C"**
   - 这是**手误/眼误型丢分**，最可惜。
   - **对策**：单选题先在题干边写"正确答案字母"，再回填，避免"脑选对、手选错"。

4. **"漏看了后半句话"**（存货监盘、抽盘）
   - 题目后半句常决定"恰当与否"。
   - **对策**：简答题先圈出"是否恰当 / 如不恰当简要说明理由"，再读 note。

## 三、你还没暴露、但注会审计极爱考的"盲区"（建议主动补）

这些在你错题里出现少或没出现，但每年必考，容易在你"以为会"的地方栽：

1. **函证**：应当函证应收账款/银行存款的例外情形；消极式函证未回函**不能认为认可**；回函须寄至事务所（转交不可靠）——你只零星错，没系统练。
2. **期初余额 / 前后任注册会计师**：期初≠上期期末（受期后事项/政策变更影响）；前任"接受委托未完成"**不算前任**。
3. **期后事项**：CPA 须**了解管理层为确保识别期后事项而建立的程序**（你综合题 48 题漏答此点）。
4. **舞弊三要素**：动机与压力 / 机会 / 态度与借口——你第 7 题把"过于乐观预期"误归态度与借口（实为动机与压力），这是经典坑。
5. **职业道德：自身利益 vs 过度推介 vs 密切关系**——"担任客户辩护人"是**过度推介**不是自身利益（你二刷第 1 题错了）。
6. **重要性体系**：整体重要性在**总体审计策略**定（非具体计划）；具体项目固有不确定性**不影响**整体重要性设定。
7. **审计工作底稿**：归档期是**事务性工作**，不涉及新程序；检查重大事项须在**出具报告前**。
