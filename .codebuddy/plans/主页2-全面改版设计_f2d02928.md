### 设计亮点

| 维度 | 设计要点 |
| --- | --- |
| **美观** | 渐变主题色横幅 + 圆角卡片 + 柔和阴影 + 卡片悬停微动效 + 科目颜色编码（会计红、审计蓝、税法橙等） |

### 新增核心功能

1. **学习中心**：动态读取各科目文件夹的笔记数量，显示距考试天数，进度条，科目颜色编码
2. **知识库**：聚合书籍/电影/播客/知乎收藏等入口，显示篇数 + 最近一条笔记标题
3. **快捷入口扩展**：从当前6个调整为收件箱、模板、闪念等更实用的入口
4. **热力图精简**：从占一整行缩减为右侧半栏
5. **科目色彩系统**：每科专属颜色（会计#E74C3C、审计#3498DB、税法#F39C12、经济法#2ECC71、战略#9B59B6、财管#1ABC9C）

## 技术方案

### 技术栈

- **渲染引擎**: DataviewJS（JavaScript 查询模式）
- **样式**: 内联 CSS（自动适配深色/浅色主题）
- **无需额外插件**: 依赖已安装的 Dataview 和 Homepage

### 架构设计

所有代码在单个 `dataviewjs` 代码块中，使用 `(async () => { ... })()` 包裹确保渲染顺序正确。

```
模块1(同步) → dv.paragraph()
模块2(同步) → dv.paragraph()  // 学习中心卡片网格
模块3(同步) → dv.paragraph()  // 知识库入口行
模块4(异步, 含await) → dv.paragraph()  // 最近编辑 + 热力图
模块5(同步) → dv.paragraph()  // 快捷入口
```

### 关键数据获取

```javascript
// 学习中心 - 动态统计各科目笔记数
const subjectPaths = {
  '会计':  { path: '"04成长/知识管理/004 注会/001 会计"',  color: '#E74C3C', exam: '2026-08-29' },
  '审计':  { path: '"04成长/知识管理/004 注会/002 审计"',  color: '#3498DB', exam: '2026-08-29' },
  '税法':  { path: '"04成长/知识管理/004 注会/006 税法"',  color: '#F39C12', exam: '2026-08-29' },
  // ... 共11个科目
};
// 使用 dv.pages(subjectPath).length 获取篇数
// 使用 counter 公式计算距考试天数
```

### 性能考虑

- 模块2（学习中心）需要在 `dv.pages()` 中执行约11次查询，但 Dataview 的查询是同步且缓存的，性能开销小
- 热力图数据从 `app.vault.getAllLoadedFiles()` 获取，只需遍历一次即可
- 异步部分仅限模块4的 `dv.io.load()`，对最近编辑笔记加载内容

### 与现有代码的关系

- 保留热力图功能但缩减尺寸（从整行改为半栏）
- 保留时间进度条（将进度集成到各科目卡片中）
- 保留倒计时（集成到科目卡片中 + 顶部概览保留）
- 新增学习中心和知识库两个大模块
- 移除"那年今日"和"今日灵感"（与当前使用场景匹配度不够高）

## 设计风格

采用 **现代信息面板 + 卡片网格** 风格，以清晰的信息层级和快速的科目入口为核心。

### 布局结构

采用纵向流式布局，从上到下 5 大模块：

1. **HEADER**：渐变背景横幅，集中展示摘要信息
2. **今日概览**：三列等宽卡片（倒计时 / 今日统计 / 待办）
3. **学习中心**：2 行科目卡片网格（CPA 6 科一行 + 中级 3 科 + 司法 + 税务师一行）
4. **知识库**：水平排列的分类入口卡片行
5. **最近动态 + 快捷入口**：最后两行收尾

### 色彩系统

采用紫色渐变主色调（`#8b5cf6` → `#3b82f6`），科目使用专属颜色编码：

- 会计：红色 `#E74C3C`
- 审计：蓝色 `#3498DB`
- 税法：橙色 `#F39C12`
- 经济法：绿色 `#2ECC71`
- 战略：紫色 `#9B59B6`
- 财管：青色 `#1ABC9C`
- 中级实务：粉色
- 中级经济法：青色
- 中级财管：金色
- 司法：深蓝
- 税务师：珊瑚红

### 交互反馈

- 科目卡片 hover 时上浮 2px + 背景加深
- 快捷入口卡片 hover 有微动效
- 热力图自带 tooltip 显示日期和篇数
- 所有可点击项都使用 `app.workspace.openLinkText()` 跳转
