# 股份支付
### 1. 与股份支付相关的条件层级梳理
1. 与股份支付相关的条件分为**可行权条件**、**非可行权条件**两大类
	1.1 可行权条件分为**服务期限条件**、**业绩条件**两类
	1.1.1 业绩条件分为**市场条件**、**非市场条件**两类

### 2. 授予日公允价值确定的考虑规则
2.1 确定权益工具在授予日的公允价值时：
- 是否考虑市场条件：**是**
- ==是否考虑非市场条件：**否**==
- ==是否考虑非可行权条件：**是==**
- 是否考虑服务期限条件：**否**

### 3. 预计可行权情况估计的考虑规则
3.1 在对预计可行权情况进行估计时：
- 是否考虑市场条件：**否**
- 是否考虑非市场条件：**是**
- ==是否考虑非可行权条件：**否==**
- 是否考虑服务期限条件：**是**

### 4. 业绩条件类股份支付的服务确认规则
4.1 对于可行权条件为业绩条件的股份支付：
- 当职工仅满足市场条件而不满足非市场条件时，企业是否应确认已取得的服务：**否**
- 当职工仅满足非市场条件而不满足市场条件时，企业是否应确认已取得的服务：**是**

- 对职工有利的修改：企业应按修改前还是修改后的条件来确认每期成本费用 **修改后**。

# 限制性股票（现金股利可撤销/不可撤销）会计处理

| 阶段      | 业务场景               | 现金股利可撤销                                                                                            | 现金股利不可撤销                                                                                   |
| ------- | ------------------ | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| **授予日** | 收到职工认股款、发行股份       | 借：银行存款（职工缴纳的认股款）<br>贷：股本（实际授予的股份数）<br>贷：资本公积——股本溢价（差额）<br><br>借：库存股（发行数量×回购价）<br>贷：其他应付款（发行数量×回购价） | 同左                                                                                         |
| **等待期** | 确认成本费用             | 借：管理费用等<br>贷：资本公积——其他资本公积                                                                          | 同左                                                                                         |
|         | 现金股利处理——可解锁部分      | 借：利润分配（可解锁部分对应的股利）<br>贷：应付股利（可解锁部分对应的股利）<br><br>借：其他应付款（可解锁部分对应的股利）<br>贷：库存股（可解锁部分对应的股利）           | ==借：利润分配（可解锁部分对应的股利）<br>贷：应付股利（可解锁部分对应的股利）==                                               |
|         | 现金股利处理——==不可解锁部分== | ==借：其他应付款（不可解锁部分对应的股利）<br>贷：应付股利（不可解锁部分对应的股利==）                                                    | ==借：管理费用等（不可解锁部分对应的股利）<br>贷：应付股利（不可解锁部分对应的股利）==                                            |
|         | 实际支付股利时            | 借：应付股利（支付的全部股利）<br>贷：银行存款（支付的全部股利）                                                                 | 同左                                                                                         |
| **解锁日** | 未达到解锁条件            | ==借：其他应付款 [回购数量×(回购价−现金股利)]<br>贷：银行存款<br><br>借：股本（需注销的股本）<br>借：资本公积——股本溢价（差额）<br>贷：库存股（回购数量×回购价==） | ==借：其他应付款（回购数量×回购价）<br>贷：银行存款<br><br>借：股本（需注销的股本）<br>借：资本公积——股本溢价（差额）<br>贷：库存股（回购数量×回购价）== |
|         | 达到解锁条件             | ==借：其他应付款 [解锁数量×(回购价−现金股利)]<br>贷：库存股<br><br>借：资本公积——其他资本公积（等待期确认的）<br>贷：资本公积——股本溢价==               | ==借：其他应付款（解锁数量×回购价）<br>贷：库存股（解锁数量×回购价）<br><br>借：资本公积——其他资本公积（等待期确认的）<br>贷：资本公积——股本溢价==     |

---

| 场景        | 可解锁（能拿到股票）        | 不可解锁（拿不到股票）        |
| --------- | ----------------- | ------------------ |
| **股利性质**  | 真正的股东分红           | 提前预发的 “过渡性股利”      |
| **可撤销时**  | 冲减回购义务（其他应付款→库存股） | 冲减回购义务（其他应付款→应付股利） |
| **不可撤销时** | 正常分红（利润分配→应付股利）   | 计入当期费用（管理费用→应付股利）  |

> [!note]
> 三、用大白话理解
> 1. 可解锁：你是股东，分红就是你的
> 不管股利可撤销 / 不可撤销，可解锁部分都按正常分红处理（借：利润分配），因为你最终是股东，拿股利天经地义。
> 2. 不可解锁：你不是股东，分红只是 “预支”
> 可撤销：企业先把股利给你，但最后你没解锁，企业能从回购款里扣回来 → 相当于冲减了要还给你的钱（其他应付款）。
> 不可撤销：企业先把股利给你，最后你没解锁也不用还 → 这部分钱就成了企业的成本（管理费用），相当于给职工的额外补偿。
> 



### 结构化有序列表版（便于背诵）
1.  **授予日**
    1.1 收到认股款并发行股份
    ```
    借：银行存款（职工缴纳的认股款）
        贷：股本（实际授予的股份数）
        贷：资本公积——股本溢价（差额）
    ```
    1.2 确认回购义务
    ```
    借：库存股（发行数量×回购价）
        贷：其他应付款（发行数量×回购价）
    ```

2.  **等待期**
    2.1 确认成本费用
    ```
    借：管理费用等
        贷：资本公积——其他资本公积
    ```
    2.2 现金股利处理
    - 可解锁部分
      - 可撤销：
        ```
        借：利润分配
            贷：应付股利
        借：其他应付款
            贷：库存股
        ```
      - 不可撤销：
        ```
        借：利润分配
            贷：应付股利
        ```
    - 不可解锁部分
      - 可撤销：
        ```
        借：其他应付款
            贷：应付股利
        ```
      - 不可撤销：
        ```
        借：管理费用等
            贷：应付股利
        ```
    2.3 实际支付股利
    ```
    借：应付股利
        贷：银行存款
    ```

3.  **解锁日**
    3.1 未达到解锁条件
    - 可撤销：
      ```
      借：其他应付款 [回购数量×(回购价−现金股利)]
          贷：银行存款
      借：股本
          借：资本公积——股本溢价（差额）
          贷：库存股（回购数量×回购价）
      ```
    - 不可撤销：
      ```
      借：其他应付款（回购数量×回购价）
          贷：银行存款
      借：股本
          借：资本公积——股本溢价（差额）
          贷：库存股（回购数量×回购价）
      ```
    3.2 达到解锁条件
    - 可撤销：
      ```
      借：其他应付款 [解锁数量×(回购价−现金股利)]
          贷：库存股
      借：资本公积——其他资本公积（等待期确认的）
          贷：资本公积——股本溢价
      ```
    - 不可撤销：
      ```
      借：其他应付款（解锁数量×回购价）
          贷：库存股（解锁数量×回购价）
      借：资本公积——其他资本公积（等待期确认的）
          贷：资本公积——股本溢价
      ```

### 补充核心逻辑说明
1. **无标的资产**：还没生产存货，亏损直接全额确认预计负债；选择违约就只按违约金确认负债、后续支付。
2. **有标的资产**：遵循**先减值、后预计负债**的顺序，先用存货跌价准备覆盖亏损，剩下的亏损才确认预计负债；选择违约时，一方面确认违约金负债，另一方面要按市价和成本的差额给已有的存货计提减值。

### 四、核心结论速记
- **终止确认**：风险报酬几乎全转走
- **继续确认**：风险报酬几乎全留下
- **继续涉入**：半转半留，且没放手控制权
- **公允价值套期**：盯**公允价值波动**，双方都进损益（特殊进其他综合收益）
- **现金流量套期**：盯**未来现金流波动**，有效部分先挂其他综合收益，无效部分进损益

1.  **折现率变更情形**：

## 💡解答
## 其他综合收益分类全解析
## 一、不能重分类进损益的其他综合收益（未来只能结转至留存收益：盈余公积、利润分配——未分配利润）
1. **其他权益工具投资的公允价值变动及汇兑损益**
这类权益工具投资一经指定不可撤销，处置时累计其他综合收益直接转入留存收益，不影响当期损益。
2. **交易性金融负债因企业自身信用风险变动引起的公允价值变动**
自身信用风险变动产生的利得损失不能计入损益操纵利润，后续结转至留存收益。
3. **重新计量设定受益计划净负债或净资产的变动额**
设定受益计划的精算利得损失等后续永久不能进损益，只能结转留存收益。
4. **权益法长投享有的被投资方不能转损益的其他综合收益份额**
跟随被投资方性质，被投资方不能重分类，投资方也只能结转留存收益。

## 二、可以重分类进损益的其他综合收益（未来处置/满足条件时转入对应损益类科目）
1. **其他债权投资公允价值变动和信用减值准备**
处置时累计其他综合收益转入**投资收益**。
2. **金融资产重分类中可进损益的其他综合收益部分**
按重分类资产类型，转入投资收益、公允价值变动损益。
3. **现金流量套期有效套期部分的利得/损失**
被套期项目影响损益时，转入套期损益、主营业务收入等对应科目。
4. **自用/存货房地产转为公允价值模式投资性房地产产生的贷方差额**
后续处置该投资性房地产时，转入**其他业务成本**冲减营业成本。
5. **外币财务报表折算差额**
处置境外经营主体时，累计折算差额转入**投资收益**。
6. **权益法长投享有的被投资方可以转损益的其他综合收益份额**
未来处置长投时，对应份额转入**投资收益**。

## 三、速记规律
- 不能重分类：大多和**权益工具、自身负债信用风险、离职后福利、被投资方不可转损益项目**相关，最终归宿都是留存收益；
- 可以重分类：大多和**债权投资、外币报表、投资性房地产、可转损益的权益法份额、套期**相关，最终归宿是当期损益类科目。

# 第十七章  收入费用利润
1. 识别客户订立的合同
	1. 合同确认条件
		1. 合同各方已批准该合同并承诺将履行各自义务；
		2. 该合同明确了合同各方与所转让的商品相关的权利和义务；
		3. 该合同有明确的与所转让的商品相关的支付条款；
		4. 该合同具有商业实质；
		5. 企业因向客户转让商品而有权取得的对价很可能收回
	2. 合同变更
		1. 合同变更增加了可明确区分的商品及价款，且新增合同价款反映了新增商品对价
			1. 都符合，按新合同处理
			2. 不满足已转让和未转让的可明确区分，==做原合同的终止，把原合同未履约部分和新合同作为新合同==
			3. 不满足且已转让和未转让的==不可明确区分==，将合同变更部分作为原合同组成部分
2. 识别客户合同单项履约义务
	1. 一、能够明确区分（需同时满足 2 点）
		1. 客户角度：该商品能够明确区分
		2. 企业角度：转让该商品的承诺在合同中是可明确区分的
	2. 二、不能明确区分（满足任一情形即可）
		1. ==需提供重大的服务以将该商品与合同中承诺的其他商品进行整合==
		2. ==该商品将对合同中承诺的其他商品予以重大修改或定制==
		3. ==该商品与合同中承诺的其他商品具有高度关联性==
	3. 三、运输费用相关判断
		1. 控制权转移给客户之前发生的运输活动：否构成单项履约义务（属于企业为履行合同发生的内部活动，相关成本计入合同履约成本）
		2. 控制权转移给客户之后发生的运输活动：可能构成单项履约义务（属于企业额外提供的运输服务，可单独作为履约义务处理）
3. 识别合同中的交易价格
	1. 可变对价
	2. 重大融资部分
	3. 非现金对价
	4. ! ==应付客户对价==
		1. ! 不构成向客户购买商品：在确认收入和支付客户对价二者输完时点，重建交易价格
		2. ！ 构成想客户购买商品，应付客户对价超过客户取得的可明确区分的商品公允价值，应当将超过金额冲减相关交易。
			1. 若客户取得可明确区分的商品公允价值不能合理估计，应当将客户的对价全部冲减交易价格
4. 将交易价格分摊至单项履约义务
	1. 分摊合同折扣
	2. 分摊合同价格
	3. 分摊合同变更对价折扣等
5. 确认收入
	1. 时段
	2. 时点收入
	3.
