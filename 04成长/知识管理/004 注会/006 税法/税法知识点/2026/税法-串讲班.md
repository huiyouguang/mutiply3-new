# 居民企业与非居民企业的区别
| 身份 | 纳税义务 | 征税范围 |
| ---- | ---- | ---- |
| 居民企业 | **无限纳税义务** | 境内所得 + 境外所得 |
| 非居民企业 | **有限纳税义务** | 境内所得 |

### 补充说明
1. 居民企业就全球范围的全部所得纳税，纳税义务覆盖境内外所有经营、投资等产生的收益。
2. 非居民企业仅针对来源于我国境内的所得承担纳税义务，境外所得无需在我国缴税。

## 💡解答
### 重要提示梳理
1. **设立机构、场所的非居民企业纳税规则**
这类企业并非完全有限纳税义务：**和境内机构、场所有实际联系的境外所得**，我国也有权对其征收企业所得税。

2. **不纳入我国征税范围的两类情况**
- 未在境内设立机构、场所的非居民企业，取得的来源于境外的所得；
- 在境内设立了机构、场所，但取得的境外所得和该境内机构、场所**无实际联系**；
以上两类所得都不需要在我国缴纳企业所得税。

# 个人所得税




### 个人所得税居民个人与非居民个人判定（高亮记忆版）

**核心规则**：个人所得税——==住所==与==居住时间==，满足其一即为居民个人。

| 类型    | 具体情况                                                           | 纳税义务及征税范围                    |
| ----- | -------------------------------------------------------------- | ---------------------------- |
| 居民个人  | ① 在中国境内==有住所==的个人   ② 在中国境内无住所，而一个纳税年度在中国境内居住累计满==183天==的个人    | 义务：**无限纳税**   范围：境内所得 + 境外所得 |
| 非居民个人 | ① 在中国境内==无住所又不居住==的个人   ② 在中国境内无住所，而一个纳税年度在境内居住累计==不满183天==的个人 | 义务：**有限纳税**   范围：境内所得        |

---

### 183天计算规则

- **计算周期**：一个纳税年度（公历1月1日至12月31日）内，在中国境内**累计**居住满183日。
- **注意一**：在中国境内有住所的，**不考虑居住时间**；无住所的纳税人才考虑居住时间。
- **注意二**：境内无住所的个人，一个纳税年度内无论出境多少次，只要**累计住满183天**，即为居民个人。

---

### 入境、离境当日处理规则

| 项目   | 作用     | 离境、入境当日处理                                |
| ---- | ------ | ---------------------------------------- |
| 居住天数 | 判定纳税义务 | 在中国境内停留满24小时的，计入居住天数；不足24小时的，**不计入**居住天数 |
| 工作天数 | 计算应纳税额 | 在中国境内停留不足24小时的，按照**半天**计算境内工作天数          |

---

### 区分意义（计税方法差异）

- **非居民个人**：工资薪金、稿酬、劳务报酬、特许权使用费所得，实行**代扣代缴**。不享有专项附加扣除
- **居民个人**：工资薪金、稿酬、劳务报酬、特许权使用费所得，实行**预扣预缴 + 年终汇算清缴**。专项扣除

---

#### 1. 租赁情形
- **经营性租赁**
  - 纳税人：**出租人**
  - 计税方式：**从租计征**（以租金收入为计税依据）
- **融资租赁**
  - 纳税人：**承租人**（实质为分期付款购买资产，承租人承担风险）
  - 计税方式：**从价计征**（以房产余值为计税依据）
  - 补充：出租人可计提折旧，承租人不能计提折旧

#### 2. 出典情形
- 纳税人：**承典人**
- 计税方式：**从价计征**

#### 3. 投资联营情形
- **承担风险**
  - 纳税人：**被投资人**（产权实质转移）
  - 计税方式：**从价计征**
- **不承担风险**
  - 纳税人：**投资人**（实质为取得固定租金收入）
  - 计税方式：**从租计征**

#### 4. 无租使用情形
- 纳税人：**使用人**（代为缴纳）
- 计税方式：**从价计征**

---

### 💡 核心记忆点
- **从租计征**：核心是取得**租金收入**，对应经营性租赁、不担风险的投资联营。
- **从价计征**：核心是**拥有/控制房产、承担风险**，对应融资租赁、出典、担风险的投资联营、无租使用。
- 融资租赁是考试高频易错点，需特别注意**纳税人是承租人**，且计税方式为从价计征。

# 耕地占用税+契税+车辆购置税 核心考点总结📌

这组课件是 **CPA 税法**中关于“权属承受人”类税种的高频考点，核心规律是：**这三类税的纳税人均为“权属的承受人”（即取得权利的一方），而非卖方/转让方**。

---

#### 1. 耕地占用税
- **核心定义**：占用耕地用于建设建筑物、构筑物或从事**非农业建设**的单位和个人。
- **纳税人判定**：
  1.  审批文件中标明的**建设用地人**；
  2.  未标明建设用地人的，**用地申请人**为纳税人；
  3.  未经批准占用的，**实际用地人**为纳税人。
- 💡 记忆点：谁实际占用耕地搞非农建设，谁就是纳税人。

---

#### 2. 契税
- **核心定义**：通过**买卖、受赠、抵债、交换、获奖、接受投资**等方式，承受不动产权属的单位和个人。
- 💡 记忆点：谁“拿到”了不动产的产权（买方、受赠方、被投资方等），谁就是契税纳税人，**卖方/转让方不缴契税**。

---

#### 3. 车辆购置税（车购税）
- **核心定义**：取得并**自用**应税车辆的单位和个人，包括：
  - 购买自用、进口自用、自产自用
  - 获奖自用、受赠自用
- **关键提示**：
  - 直接从境外进口 → 按“进口自用”计税；
  - 在境内购买的进口车辆 → 按“购买自用”计税。
- 💡 记忆点：只要是“自己用”，无论通过什么方式取得车辆，都要交车购税；如果是买来卖去的经销商，则不缴。

---

### 💡 共性规律总结
这三个税种都遵循**“承受方纳税”**的原则：
- 耕地占用税：承受耕地使用权（用于非农建设）
- 契税：承受不动产所有权
- 车购税：承受车辆所有权并自用

这是考试中极易混淆的考点，记住“**谁拿权谁交税，卖方不交**”就能快速判断纳税人。

## 代扣代缴问题


### 增值税代扣代缴义务人核心考点📌

这组课件是CPA税法中**增值税代扣代缴**的高频考点，核心是明确“谁来替境外方/自然人缴税”。

---

#### 一、境外单位/个人在境内发生应税交易
- **适用场景**：境外单位或个人在境内发生应税交易，且**在境内未设立经营机构**。
- **代扣代缴义务人**：**境内购买方**。
- **计税方法**：扣缴义务人应按照**销售额×税率**计算应扣缴税额（不适用征收率）。
- **关键提示：进口货物 vs 进口服务**

| 类型 | 征税主体 | 抵扣凭证 |
|------|----------|----------|
| 进口货物 | 海关代征增值税 | 海关开具的增值税专用缴款书 |

#### 二、自然人发生符合规定的应税交易
- **代扣代缴义务人**：**支付价款的境内单位**（即向自然人付款的境内企业/单位）。（新增）
- 💡 记忆点：只要是向境外方或特定自然人支付款项，且对方在境内无机构，**付款方就负有代扣增值税的义务**。


### （二）城建税
负有增值税、消费税扣缴义务的单位和个人，在扣缴增值税、消费税的同时扣缴城市维护建设税。

【易错点】进口货物或服务、无形资产的单位和个人，是增值税、消费税的纳税人，但不是城建税的纳税人。（进口不征）

### （三）企业所得税
未设机构、场所的非居民企业或虽设立机构、场所但取得的境内所得与境内机构、场所没有联系——境内支付方代扣代缴企业所得税。

### （四）个人所得税
个人取得的工资、劳务报酬、稿酬、特许权使用费、分类所得——支付方预扣预缴或代扣代缴。

### 企业所得税代扣代缴情形及境内外所得确定原则

#### 一、企业所得税代扣代缴情形
企业所得税代扣代缴的核心判断标准：**是否构成境内所得**。
- 适用对象：非居民企业
  1.  在境内未设立机构、场所；
  2.  虽设立机构、场所，但取得的所得与其所设机构、场所没有实际联系。
- 扣缴规则：应当就其来源于**境内所得**，由**境内支付方**代扣代缴企业所得税。

---

#### 二、境内、境外所得确定原则
| 所得类型 | 确定原则 |
|----------|----------|
| 销售货物所得 | 按照**交易活动发生地**确定 |
| 提供劳务所得 | 按照**劳务发生地**确定 |
| 不动产转让所得 | 按照**不动产所在地**确定 |
| 动产转让所得 | 按照**转让动产的企业或者机构、场所所在地**确定 |
| 权益性投资资产转让所得 | 按照**被投资企业所在地**确定 |
| 股息、红利等权益性投资所得 | 按照**分配所得的企业所在地**确定 |
| 利息所得、租金所得、特许权使用费所得 | 按照**负担、支付所得的企业或者机构、场所所在地**确定，或按照**负担、支付所得的个人的住所地**确定 |

💡 **代扣代缴触发条件**：非居民企业取得**境内所得**且无境内机构场所，或所得与境内机构场所无实际联系时，由境内支付方代扣代缴。

### 混合销售 vs 兼营
---
#### 1. 混合销售
- **核心特征**：**一项交易**，同时涉及**两个不同税率/征收率**的应税项目（货物+服务）。
- **计税规则**：按**主要业务**适用的税率/征收率统一计税。

#### 2. 兼营
- **核心特征**：**不同交易**，分别适用不同税率/征收率。
- **计税规则**：
  - 分别核算：按各自税率/征收率分别计税
  - 未分别核算：从高适用税率/征收率

| :--- | :--- | :--- |
| **共同点** | 均按 **配比原则** 扣除 | 均按 **配比原则** 扣除 |
| **可扣除的土地相关支出** | 仅限于：**出让金 + 拆迁补偿费 + 土地前期开发费** | 土地支付金额包括 **出让金 + 契税**；征地和拆迁补偿费、土地前期开发费用计入 **房地产开发成本** |
| **是否包括契税** | ==不包括契税== | ==包括契税==（计入土地支付金额） |
| **扣除路径** | 直接从销售额中扣减 | 计入扣除项目金额（土地成本或开发成本） |

---

### 3. 配比原则具体应用（计算题关键）

- 增值税当期允许扣除的土地价款公式：

\[
\text{当期允许扣除的土地价款} = \frac{\text{当期销售建筑面积}}{\text{可供销售建筑面积}} \times \text{支付的土地价款}
\]

- **分母“可供销售建筑面积”**：指项目可售总面积，但不包括 **未单独作价结算的配套公共设施**（如物业用房、幼儿园等）。
- **用途**：用于 **一般计税项目**，老项目或简易计税不适用。

---

### 4. 常见命题陷阱（避坑点）

| 陷阱 | 正解 |
| :--- | :--- |
| 把契税放进增值税扣减项 | ❌ 增值税（一般计税）扣土地价款时 ==不含契税== |
| 可供销售建筑面积算上公共配套 | ❌ 需排除 ==未单独作价结算== 的配套公共设施 |
| 土地增值税把土地前期开发费计入土地价款 | ❌ 土增税中计入 **开发成本**，不是土地价款 |
| 非房地产企业卖房也按此公式 | ❌ 只适用于 **房地产开发企业自行开发项目** |

## 增值税——销售额的确认（建筑企业 vs 房地产企业 + 非房地产企业转让不动产）

### 一、建筑企业与房地产开发企业的计税方法对比（高频对比题）

| 企业类型 | 适用计税方法 | 销售额确定方式 |
| :--- | :--- | :--- |
| **建筑企业** | 简易计税 | ==差额==确定销售额 |
| **建筑企业** | 一般计税 | ==全额==确定销售额 |
| **房地产开发企业** | 简易计税 | ==全额==确定销售额 |
| **房地产开发企业** | 一般计税 | ==差额==确定销售额 |

> ✅ 记忆口诀（仅辅助）：  
> 建筑简易差，建筑一般全；  
> 房建简易全，房建一般差。

---

### 二、非房地产企业转让取得的不动产（先买后卖）

| 项目 | 内容 |
| :--- | :--- |
| **适用情形** | 非房地产企业转让 **2016年4月30日前取得** 的不动产，选择 **简易计税方法** |
| **销售额公式** | 销售额 = 全部含税销售额 － **不动产购置原价或取得不动产时的作价** |
| **可扣除金额** | 按 **契税凭证上记载的金额** 或购置发票记载的不动产购置原价 |
| **不可扣除** | ==不包括契税本身==（即契税不能作为扣减项从销售额中剔除） |

---

### 三、增值税 vs 土地增值税：非房地产企业转让旧房时的扣除差异

| 对比维度 | 增值税（简易计税） | 土地增值税 |
| :--- | :--- | :--- |
| **扣除依据** | 按购置发票或契税凭证记载的 **购置原价/作价** | 能取得评估价格的，按 **评估价格** 扣除；不能取得评估价格的，按 **发票加计扣除法** |
| **契税能否扣除** | ==不能扣除== 契税本身 | 能取得评估价格时，契税已包含在 **评估价格** 中扣除；不能取得评估价格时，契税可 **作为税金** 单独扣除 |
| **扣除对象** | 仅扣除不动产购置原价 | 可扣除：土地价款+开发成本+开发费用+税金+加计扣除（旧房评估价模式或发票模式） |

---

### 四、专项提示（避坑要点）

| 类别            | 关键区别                                  |
| :------------ | :------------------------------------ |
| **增值税扣减项**    | 仅允许扣除 **购置原价**（契税凭证上记载的金额），==不含契税==   |
| **土地增值税扣除项**  | 评估价格模式下，契税包含在评估价格中；发票模式下，契税作为税金项目单独扣除 |
| **建筑企业差额扣除**  | 简易计税下差额扣除的是 **分包款**，不同于房地产企业扣除土地价款    |
| **房地产企业差额扣除** | 一般计税下差额扣除的是 **向政府部门支付的土地价款**，不含契税     |

## 增值税——纳税义务发生时间

### 一、一般规定

| 触发情形 | 纳税义务发生时间 |
| :--- | :--- |
| **发生应税交易** | ==收讫销售款项==的当日 **或** ==取得索取销售款项凭据==的当日（以两者中**较早**者为准） |
| **先开具发票的** | ==开具发票==的当日 |

| **发生视同应税交易** | ==完成视同应税交易==的当日（货物发出/金融商品所有权转移/无形资产或不动产转让完成） |

## 增值税——进项税额的抵扣（计算抵扣）

### 一、农产品进项税额抵扣

| 抵扣情形 | 抵扣方式 | 计算公式 / 规则 | 特殊提示 |
| :--- | :--- | :--- | :--- |
| **取得一般纳税人开具的专票或海关缴款书** | 凭票抵扣 | 以专票或缴款书上注明的==税额==为进项税额 | 按票面税额直接抵扣 |
| **从小规模纳税人处取得专票（3%征收率）** | 计算抵扣 | 进项税额 = 专票上注明的==金额 × 9%== | 按金额和扣除率计算，非按票面税额 |
| **取得（开具）农产品销售发票或收购发票** | 计算抵扣 | 进项税额 = 买价 × ==9%== | 买价为发票上注明的收购价款 |
| **从批发、零售环节购进免税蔬菜、部分鲜活肉蛋** | ==不得抵扣== | 无论有无发票，均不得计算抵扣进项税额 | 属于最终消费环节，已免税，进项税链条终止 |
| **烟叶产品** | 计算抵扣 | 准予抵扣的进项税额 =（收购烟叶实际支付的价款总额 + 烟叶税应纳税额）× 扣除率 | 扣除率同一般农产品（==9%==） |


### 二、烟叶产品进项税额抵扣——详细计算

| 项目 | 计算规则 | 特殊提示 |
| :--- | :--- | :--- |
| **烟叶税计算口径** | 实际支付的价款总额 = 收购价款 ×（1 + ==10%==） | 价外补贴统一按收购价款的 ==10%== 计算（无论实际支付多少） |
| **进项税抵扣口径** | 实际支付的价款总额 = 收购价款 + 实际支付给烟农的价外补贴 | 此处为实际支付的价外补贴（实付数），非10%统一口径 |
| **烟叶税应纳税额** | 烟叶税额 = 收购烟叶实际支付的价款总额 × 税率（==20%==） | 税率固定为 ==20%== |
| **准予抵扣的进项税额** | （收购烟叶实际支付的价款总额 + 烟叶税额）× 扣除率（==9%==） | 买价中已包含烟叶税，不得重复计算 |


### 三、购进国内旅客运输服务——进项税额抵扣

| 凭证类型 | 抵扣方式 | 计算公式 | 特殊提示 |
| :--- | :--- | :--- | :--- |
| **增值税电子普通发票** | 凭票抵扣 | 发票上注明的税额 | 抬头须为公司名称 |
| **注明旅客身份信息的航空运输电子客票行程单** | 计算抵扣 | （票价 + 燃油附加费）÷（1 + ==9%==）× ==9%== | ==不含==民航发展基金（机场建设费） |
| **注明旅客身份信息的铁路车票** | 计算抵扣 | 票面金额 ÷（1 + ==9%==）× ==9%== | 仅限高铁、动车、火车等 |
| **注明旅客身份信息的公路、水路客票** | 计算抵扣 | 票面金额 ÷（1 + ==3%==）× ==3%== | 仅限境内公路、水路运输 |

#### 国内旅客运输服务抵扣的限定条件

| 限定条件 | 具体要求 |
| :--- | :--- |
| **人员范围** | 仅限于本企业的 ==签订劳动合同的员工== 和 ==劳务派遣用工==，不包括外部客户、专家、临时来访人员等 |
| **境内境外** | 必须是 ==境内== 发生的旅客运输服务，境外发生的不得抵扣 |
| **用途限制** | 用于集体福利或个人消费的，不得抵扣（即使取得合法凭证） |


### 四、通行费进项税额抵扣

| 通行费类型 | 抵扣方式 | 计算公式 / 规则 | 特殊提示 |
| :--- | :--- | :--- | :--- |
| **高速公路、一级、二级公路通行费** | 凭票抵扣 | 须取得左上角标识==“通行费”==字样的增值税电子普通发票，按发票上注明的税额抵扣 | 纸质通行费发票 ==不得抵扣==；ETC充值后索取的不征税普票不得抵扣 |
| **桥、闸通行费** | 计算抵扣 | 可凭取得的通行费发票（不含财政票据）计算抵扣：<br>桥、闸通行费可抵扣进项税额 = 发票注明金额 ÷（1 + ==5%==）× ==5%== | 不区分是一级/二级/高速，仅按桥闸单独处理；财政票据（行政事业性收费）==不得抵扣== |


### 五、易错易混点归纳

| 易错场景               | 正确规则                                   |
| :----------------- | :------------------------------------- |
| 从小规模纳税人取得3%专票购买农产品 | 按 ==金额×9%== 计算抵扣，不是按票面3%税额抵扣（高亮：扣除率9%） |
| 从批发零售环节购进免税蔬菜、鲜活肉蛋 | ==无论有无发票，均不得抵扣==（已属于最终流通环节，免税链条终止）     |
| 烟叶产品买价             | 买价中包含 ==烟叶税==，计算进项抵扣时已包含烟叶税额，不得再单独加计   |
| 收购烟叶计算烟叶税时的价外补贴    | 统一按收购价款的 ==10%== 计算（无论实际支付多少）          |
| 收购烟叶计算进项抵扣时的价外补贴   | 按 ==实际支付== 给烟农的价外补贴金额（实付数）             |
| 旅客运输服务：外部客户        | ==不得抵扣==（仅限合同工和劳务派遣工）                  |
| 旅客运输服务：境外行程        | ==不得抵扣==（仅限境内发生的旅客运输服务）                |

## 增值税——进项税额的抵扣（特殊情形）

### 一、可抵扣的特殊情形

| 类别 | 具体项目 | 特殊提示 |
| :--- | :--- | :--- |
| **可抵扣的非应税交易** | 法定非应税交易 | 虽不属于应税交易范围，但按规定可抵扣进项税额的情形 |
| **可抵扣的非应税交易** | 符合条件的资产重组 | 资产重组过程中，涉及的货物、不动产、土地使用权等转让行为，不征收增值税，但符合条件的可按规定抵扣进项税额 |
| **可抵扣的非应税交易** | 税收优惠 | 适用增值税即征即退、先征后退等优惠政策的，其进项税额可按相关规定抵扣 |


### 二、不可抵扣进项税额的情形

#### （一）特定用途

| 适用情形 | 具体项目 | 特殊提示 |
| :--- | :--- | :--- |
| **特定用途不得抵扣** | 简易计税项目 | 用于简易计税方法计税项目的购进货物、服务等 |
| **特定用途不得抵扣** | 免税项目 | 用于免征增值税项目的购进货物、服务等 |
| **特定用途不得抵扣** | 集体福利 | 用于集体福利的购进货物、服务等（如食堂、职工宿舍等） |
| **特定用途不得抵扣** | 个人消费 | 用于个人消费的购进货物、服务等（如交际应酬、礼品等） |
| **特定用途不得抵扣** | 不得抵扣的非应税交易 | 用于税法规定的不得抵扣进项税额的非应税交易项目 |


#### （二）非正常损失——进项税额转出

| 损失类型      | 涉及项目                                        | 特殊提示                       |
| :-------- | :------------------------------------------ | :------------------------- |
| **非正常损失** | 购进货物及相关的加工修理修配劳务和交通运输服务                     | 已抵扣的进项税额须作==进项税额转出==处理     |
| **非正常损失** | 在产品、产成品耗用的购进货物（==不包括固定资产==）、加工修理修配劳务和交通运输服务 | 固定资产所耗用的货物不属于非正常损失转出范围     |
| **非正常损失** | 不动产，以及不动产所耗用的购进货物和建筑服务，==设计服务没了==           | 已抵扣进项税额按不动产净值率计算转出         |
| **非正常损失** | 不动产在建工程所耗用的购进货物和建筑服务                        | 尚未完工的在建工程发生非正常损失，相关进项税额须转出 |

> **非正常损失的定义**：指因 ==管理不善== 造成货物被盗、丢失、霉烂变质，以及因 ==违反法律法规== 造成货物或者不动产被依法没收、销毁、拆除的情形。
>
> ✅ 注意区分：
> - 自然灾害损失（如洪水、地震）→ 不属于非正常损失 → 进项税额可正常抵扣
> - 管理不善/违法造成的损失 → 属于非正常损失 → 进项税额不得抵扣，已抵扣的须转出


### 三、进项税额转出计算——无法划分用途的公式

| 适用情形 | 计算公式 | 特殊提示 |
| :--- | :--- | :--- |
| **兼营简易计税、免税、不得抵扣非应税交易，无法划分不得抵扣进项税额** | **当期不得抵扣的进项税额 = 当期无法划分的全部进项税额 ×（当期简易计税项目销售额 + 当期免税项目销售额 + 当期不得抵扣非应税交易收入）÷（当期全部销售额 + 当期全部非应税交易收入）** | 逐期计算当期不得抵扣的进项税额，并于 ==次年1月== 的纳税申报期内进行 ==全年汇总清算==（多退少补） |


### 四、易错点归纳

| 易错场景            | 正确规则                                                               |
| :-------------- | :----------------------------------------------------------------- |
| 非正常损失中固定资产耗用的货物 | ==固定资产本身== 的损失不涉及进项税转出（已通过折旧扣除），但 ==固定资产所耗用的货物== 也不属于转出范围（高亮：固定资产） |
| 非正常损失与自然灾害      | 自然灾害损失 ==不属于== 非正常损失，进项税额可正常抵扣，无需转出                                |
| 无法划分用途的进项税额处理   | 先按 ==销售额占比== 计算当期不得抵扣额，再于 ==次年1月== 做 ==全年汇总清算==                    |
| 资产重组涉及的进项税      | 符合条件的资产重组过程中，按规定可抵扣进项税额，不属于不得抵扣情形                                  |
| 集体福利领用库存商品      | 已抵扣进项税额须作 ==进项税额转出==；若领用的商品属于免税或简易计税项目购入，则从未抵扣过，无需转出               |


## 增值税——进项税额的抵扣（不可抵扣——特定服务）

### 不可抵扣——特定服务

| 类别 | 具体项目 | 特殊提示 |
| :--- | :--- | :--- |
| **不可抵扣——特定服务** | 接受的贷款服务 | 利息支出，以及与该笔贷款直接相关的投融资顾问费、手续费、咨询费等费用，进项税额==不得抵扣== |
| **不可抵扣——特定服务** | 购进并直接用于消费的餐饮服务 | 进项税额==不得抵扣==（高亮：直接用于消费） |
| **不可抵扣——特定服务** | 购进并直接用于消费的居民日常服务 | 进项税额==不得抵扣== |
| **不可抵扣——特定服务** | 购进并直接用于消费的娱乐服务 | 进项税额==不得抵扣== |
| **不可抵扣——特定服务（保险服务）** | 保险公司以现金赔付方式承担机动车辆保险责任 | 将应付给被保险人的赔偿金直接支付给车辆修理劳务提供方，==不属于==保险公司购进车辆修理劳务，其进项税额==不得抵扣== |


### 易错点归纳

| 易错场景 | 正确规则 |
| :--- | :--- |
| 贷款利息支出能否抵扣 | 贷款利息及直接相关的投融资顾问费、手续费、咨询费等，==一律不得抵扣== |
| 餐饮服务能否抵扣 | 购进餐饮服务用于生产经营（如会议用餐）是否可抵扣？——==无论用途，只要“购进并直接用于消费”的餐饮服务，均不得抵扣==（餐饮服务一经消费即终结，无法区分是否用于生产经营） |
| 保险赔付车辆修理费专票 | 保险公司将赔款直接支付给修理方，不构成保险公司购进修理劳务，修理方开具的专票是开给被保险人的（因被保险人提供了车辆），==保险公司不得抵扣==该进项税额；被保险人取得修车发票后，因属于保险赔偿范围内的支出，也不得作为进项税抵扣（否则双重利益）。 |
| 区分：购进的住宿服务与餐饮服务 | 住宿服务可用于生产经营（如差旅住宿），取得专票可抵扣；餐饮服务==无论是否用于生产经营，均不得抵扣== |

## 增值税——进项税额的抵扣（长期资产）

### 一、长期资产进项税额抵扣的基本规则

| 资产类型 | 用途情形 | 抵扣方法 | 特殊提示 |
| :--- | :--- | :--- | :--- |
| **有形动产类固定资产、无形资产、不动产** | 专用于一般计税项目 | 取得时 ==全额一次性抵扣== | 无论资产原值金额大小 |
| **有形动产类固定资产、无形资产、不动产** | 专用于五类不得抵扣项目（简易计税、免税、集体福利、个人消费、不得抵扣非应税交易） | 取得时 ==不得抵扣== | 已抵扣的须作进项税额转出 |
| **有形动产类固定资产、无形资产、不动产（原值 ==500万元== 以下）** | 用作混合用途（兼用） | 取得时 ==全额一次性抵扣== | 兼用指同时用于一般计税项目和不得抵扣项目 |
| **有形动产类固定资产、无形资产、不动产（原值 ==500万元== 以上）** | 用作混合用途（兼用） | 购进时先 ==全额抵扣==，此后在用于混用期间，根据调整年限，==逐年==从销项税额中抵扣不得抵扣的进项税额 | 不得抵扣的进项税额按资产净值率计算，分年调整 |


### 二、2026年1月1日前后长期资产进项税额抵扣的适用规则

| 取得时间 | 资产状态 | 抵扣规则 | 特殊提示 |
| :--- | :--- | :--- | :--- |
| **2026年1月1日后（含当日）** 取得 | 新购入长期资产 | 按上述基本规则执行（全额一次性抵扣或不得抵扣） | 适用新政策口径 |
| **2025年12月31日前（含当日）** 取得，且在2026年1月1日后完成资本化改造 | 原有长期资产进行资本化改造 | 改造部分按取得时点的政策执行；后续抵扣规则按改造完成后的资产用途重新判定 | 注意区分“改造完成日”与“资产取得日”，不同时点适用不同抵扣规则 |


### 三、易错点归纳

| 易错场景                  | 正确规则                                      |
| :-------------------- | :---------------------------------------- |
| 兼用资产原值500万元以下         | ==全额一次性抵扣==，不需要分年调整（无论是否混用）               |
| 兼用资产原值500万元以上         | 先全额抵扣，再 ==逐年调整==不得抵扣部分                    |
| 专用于不得抵扣项目的长期资产        | 取得时 ==不得抵扣==，不存在“先抵后转”                    |
| 2025年底前取得、2026年后改造的资产 | ==改造部分==应视同新取得资产的抵扣规则处理，不能简单按原取得时间统一适用旧政策 |
