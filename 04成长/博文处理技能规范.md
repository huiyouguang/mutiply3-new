# 博文处理技能规范

## 一、技能概述

本技能用于将**播客逐字稿、文章内容、笔记素材**等原始内容，处理为符合本 vault 规范的标准化博文（.md 文件），存放于 `03Life os/播客生活/` 目录。

### 处理流程

```
原始内容（用户发送的文本/链接/文件）
    ↓
① 内容解析与去噪（去除口语填充词、重复语句，保留核心表达）
    ↓
② 结构化整理（分段、提炼小标题、加粗金句）
    ↓
③ 前元数据撰写（Title, 播客/来源, 收藏标签, 创建时间等）
    ↓
④ 输出标准化博文
```

---

## 二、文件命名规范

### 2.1 通用格式

```
{标题核心}｜{副标题/补充信息}.md
```

用全角竖线 `｜` 分隔主副标题。

### 2.2 命名规则

| 来源类型 | 命名示例 |
|---------|---------|
| 播客笔记 | `自我进化论｜No.71：由心而发，唤醒创造力.md` |
| 访谈文章 | `纳瓦尔访谈-人生只有一次，关于44条人性的真相.md` |
| 演讲/视频 | `我走了十年的路才明白的道理.md` |
| 读书笔记 | `《原子习惯》——微小改变带来巨大结果.md` |

### 2.3 命名原则

1. **信息密度高**：标题要概括核心主题，让人一眼看出内容方向
2. **避免过长的后缀**：若标题本身已清晰，无需加副标题
3. **保持风格一致**：播客系列保持 `{播客名}｜No.{期数}：{主题}.md` 格式
4. **特殊字符**：只能用 `｜`、`《》`、`——`、`：`、`·`、空格（半角），禁止使用 `/ \ : * ? " < > |`

## 三、前元数据（Frontmatter）规范

每篇博文必须包含以下前元数据：

```yaml
---
标题: 完整的博文标题（与文件名标题主体一致，不含 .md）
播客: 来源播客名称（若是播客内容必填，否则可省略）
来源: 原始链接/出处（可选）
收藏标签: 标签1, 标签2, 标签3（3-6个，涵盖主题领域）
季号: 1（播客系列时的期号，非播客可省略）
结束日期: 2026-06-21T12:00:00.000Z（整理完成时间）
文件分类: 播客生活（固定值）
科目类别: 播客生活（固定值）
创建时间: 2026-06-21T12:00:00.000Z
章节: 所属主题章节（如：创作与创造力, 人生哲学, 财富自由等）
困难程度: 简单（默认）
主要程度: 核心（默认，重要内容）/ 普通（一般内容）
分值: 8（1-10，根据内容价值评定）
words:
  2026-06-21: 0（待后续统计字数时更新）
---
```

### 元数据填写规则

| 字段 | 必填 | 说明 |
|------|------|------|
| `标题` | ✅ | 完整的显示标题，与文件名标题一致 |
| `播客` | ❌ | 如是播客内容则必填，注明播客名称 |
| `来源` | ❌ | 原始链接 |
| `收藏标签` | ✅ | 3-6个，参考已有标签体系 |
| `结束日期` | ✅ | 完成整理的日期时间 |
| `文件分类` | ✅ | 固定为 `播客生活` |
| `科目类别` | ✅ | 固定为 `播客生活` |
| `创建时间` | ✅ | 实际整理时间 |
| `章节` | ✅ | 归类到已有章节体系 |
| `困难程度` | ✅ | 默认 `简单` |
| `主要程度` | ✅ | 根据内容重要性选择 `核心` 或 `普通` |
| `分值` | ✅ | 1-10，综合评定内容价值 |

## 四、正文格式规范

### 4.1 内容结构

```
# {标题}
（正文内容，保留播客开头的自我介绍/开场白 1-2 段作为前言）

## 1 {一级标题}
### 1.1 {二级标题}（可选）
正文段落...

**核心金句用加粗高亮标注**

## 2 {一级标题}
...
```

### 4.2 格式规则

1. **一级标题**：`# {标题}`（仅一个，与文件名对应）
2. **二级标题**：`## 1 {标题}`（数字+空格+标题，数字从1开始递增）
3. **三级标题**：`### 1.1 {标题}`（仅在需要时使用，数字分层）
4. **金句加粗**：关键洞察、核心观点用 `**金句内容**` 包裹
5. **高亮金句**：特别重要的金句，用 `**金句内容**` 包裹
6. **引文/引用**：直接引用用 `>` 标记
7. **列表**：相关要点用 `- 项目` 无序列表

### 4.3 内容处理要求

| 操作 | 说明 |
|------|------|
| **去口语化** | 去除"嗯、啊、就是、然后"等填充词，保留说话风格 |
| **合并重复** | 同一观点重复表述时合并，保留最精炼版本 |
| **分段** | 每段 3-8 行，逻辑独立 |
| **提炼小标题** | 每个自然段落块归纳一个**主题性小标题** |
| **保留故事感** | 保留具体故事、案例、类比，这些是内容精华 |
| **删除无关互动** | 如"大家可以扣个1"等直播互动语句可去除 |
| **保留推荐信息** | 若内容提及书籍、课程、人名等，保留并可在文末标注 |
