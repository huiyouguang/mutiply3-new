## 六、技术架构

### 1. 全局对象层级

```
window.__mcyo (主页2框架)
  ├── dashboardData (指向 window.__dashboard_data)
  └── ...

window.__dashboard_data (全局数据对象)
  ├── totalNotes
  ├── allTags
  ├── useDays
  ├── NOW
  ├── getProgress(start, end, now)
  ├── readHealthData(date)
  └── _ready: true

window.__health (健康追踪框架)
  ├── readHealthFile(date)
  ├── writeHealthFile(date, data)
  ├── loadAllHealthData()
  └── ...
```

### 2. 数据流向

```
健康追踪.md (记录数据)
  → TaskNotes/健康数据/YYYY-MM-DD.md (持久化存储)
  → window.__dashboard_data.readHealthData(date) (全局读取函数)
  → 主页2.md (健康概览模块显示)
  → 仪表盘.md (健康数据概览显示)
```

## 七、注意事项

1. **文件路径统一**：健康数据统一存储在 `TaskNotes/健康数据/YYYY-MM-DD.md`
2. **全局对象命名**：
   - 主页2使用 `window.__mcyo`
   - 健康追踪使用 `window.__health`
   - 数据共享使用 `window.__dashboard_data`
3. **模块ID唯一**：三个主页的模块ID不能重复，避免DOM冲突
4. **数据一致性**：所有主页都从同一文件读取健康数据，确保数据一致
