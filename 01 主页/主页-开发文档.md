## 四、核心 API 函数

### 4.1 导航到文件/文件夹

```javascript
function navigateTo(path) {
  let abs = app.vault.getAbstractFileByPath(path);
  if (!abs) abs = app.vault.getMarkdownFiles().find(f => f.basename === path);
  if (abs && abs.children) {
    const files = app.vault.getMarkdownFiles().filter(f => f.path.startsWith(path));
    if (files.length > 0) app.workspace.getLeaf(false).openFile(files[0]);
  } else if (abs) {
    app.workspace.getLeaf(false).openFile(abs);
  }
}
```

**用法**：`navigateTo('04成长/知识管理/004 注会/001 会计')`

### 4.2 任务勾选

```javascript
function toggleTask(path, line) {
  const file = app.vault.getAbstractFileByPath(path);
  if (!file) return;
  app.vault.read(file).then(content => {
    const lines = content.split('\n');
    // 切换 [ ] ↔ [x]
    lines[line] = lines[line].replace('[ ]', '[x]'); // or reverse
    app.vault.modify(file, lines.join('\n'));
  });
}
```

## 五、代码模式速查

### ✅ 多块架构模式（当前架构）

```javascript
// [Setup 块] - 计算共享数据
(async () => {
  const container = dv.container;
  while (container.firstChild) container.removeChild(container.firstChild);
  const C = { /* 色彩系统 */ };
  const allMd = app.vault.getAllLoadedFiles().filter(f => f.extension === 'md');
  window.__mcyo = { C, navigateTo, toggleTask, allMd, totalNotes, allFilePaths };
})();
```

```dataviewjs
// [后续块] - 读取共享数据
(async () => {
  const __m = window.__mcyo; if (!__m) return;
  const { C, navigateTo, allMd } = __m;
  // 在此块内独立渲染模块
})();
```

### ✅ 正确：dv.el() + innerHTML + querySelectorAll

```javascript
const mod = dv.el('div', '');
mod.style.cssText = `background:${C.card};border-radius:16px;padding:16px 20px;margin-bottom:16px;`;
mod.innerHTML = `<a data-path="${p.file.path}" href="#">文本</a>`;
mod.querySelectorAll('a[data-path]').forEach(el => {
  el.addEventListener('click', (e) => { e.preventDefault(); navigateTo(el.dataset.path); });
});
```

### ✅ 正确：createEl + addEventListener

```javascript
const card = container.createEl('a');
card.addEventListener('click', (e) => { e.preventDefault(); navigateTo(path); });
```

### ❌ 禁止：dv.paragraph() 渲染 HTML

```javascript
// ⚠️ 会导致双重渲染！HTML 同时被 markdown 解析器和 DOM 解析器处理
dv.paragraph(`<div id="id" style="...">内容</div>`);
```

### ❌ 禁止：inline onclick

```html
<!-- 这在 Obsidian 中会被过滤，无法点击 -->
<a href="#" onclick="navigateTo('path')">文本</a>
```

## 六、如何添加新模块

### 步骤

1. **选择目标代码块**：5 个 Block 按功能分组，找到最合适的位置
2. **获取共享状态**：`const __m = window.__mcyo; const { C, navigateTo } = __m;`
3. **选择渲染方式**：
   - 需要交互 → `dv.el()` + `innerHTML` + `querySelectorAll` 绑定事件
   - 复杂 DOM → `document.createElement()` + `addEventListener`
4. **使用色彩系统**：引用 `${C.card}`, `${C.accent}` 等变量
5. **独立 try-catch**：每个块已有 try-catch，新增模块自然被保护
6. **JS 语法验证**：刷新 Obsidian 前确认无语法错误

### 模板代码（在某 Block 内追加）

```javascript
// ─── 模块 N: 新模块名称 ───
const newMod = dv.el('div', '');
newMod.style.cssText = `background:${C.card};border-radius:16px;padding:16px 20px;margin-bottom:16px;border:1px solid ${C.border};box-shadow:0 2px 12px rgba(0,0,0,0.05);`;
newMod.innerHTML = `
  <div style="font-size:15px;font-weight:600;color:${C.text};margin-bottom:10px;">🎯 模块标题</div>
  <div>模块内容</div>`;
// 事件绑定
newMod.querySelectorAll('a[data-path]').forEach(a => {
  a.addEventListener('click', (e) => { e.preventDefault(); navigateTo(a.dataset.path); });
});
```

### 跨块共享数据

如果新模块的计算结果需被后续块使用，在 Block 内追加：
```javascript
window.__mcyo_extra = { newVar1, newVar2 };
```
后续块中读取：
```javascript
const __e = window.__mcyo_extra || {};
```

## 八、常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 内容重复显示两遍 | `dv.paragraph()` 传入 HTML 导致双重渲染（markdown + DOM 各渲染一次） | **全局替换为** `dv.el()` + `innerHTML` |
| Setup 块已渲染但后续块空白 | `window.__mcyo` 变量名不匹配 | 确认使用 `window.__mcyo`（双下划线），不是 `window.mcyo` |
| 点击不跳转 | inline onclick 被 Obsidian 过滤 | 改用 `addEventListener` |
| 页面空白 | JS 语法错误 | 每个块独立 try-catch 会打印错误信息 |
| 模块间距不均 | 缺少统一 margin | 所有卡片 `margin-bottom:16px` |
| 双列不对齐 | grid 默认 stretch | 加 `align-items:start` |
| CPA 卡片只显示部分科目 | 旧版过滤了已完成章节 | 现改为 `allChapters` 显示全部 |
| CPA 任务数对不上 | 科目识别被全局标签污染 | 使用 `cleanTxt` 先剥离 `#project/` 再匹配 |
