## 四、核心 API 函数

### 4.1 导航到文件/文件夹

```javascript
function navigateTo(path) {
  let abs = app.vault.getAbstractFileByPath(path);
  if (!abs) abs = app.vault.getMarkdownFiles().find(f => f.basename === path);
  if (abs && abs.children) {
    const files = app.vault.getMarkdownFiles().filter(f => f.path.startsWith(path));
    if (files.length > 0) app.workspace.getLeaf(false).openFile(files[0]);
  } else if (abs) {
    app.workspace.getLeaf(false).openFile(abs);
  }
}
```

**用法**：`navigateTo('04成长/知识管理/004 注会/001 会计')`

### 4.2 任务勾选

```javascript
function toggleTask(path, line) {
  const file = app.vault.getAbstractFileByPath(path);
  if (!file) return;
  app.vault.read(file).then(content => {
    const lines = content.split('\n');
    // 切换 [ ] ↔ [x]
    lines[line] = lines[line].replace('[ ]', '[x]'); // or reverse
    app.vault.modify(file, lines.join('\n'));
  });
}
```

## 五、代码模式速查

### ✅ 正确：innerHTML + querySelectorAll 绑定事件

```javascript
const mod = dv.el('div', '');
mod.innerHTML = `<a data-path="${p.file.path}" href="#">文本</a>`;
mod.querySelectorAll('a[data-path]').forEach(el => {
  el.addEventListener('click', (e) => { e.preventDefault(); navigateTo(el.dataset.path); });
});
```

### ✅ 正确：纯 dv.paragraph() 渲染

```javascript
const id = 'uniq-' + Date.now();
dv.paragraph(`<div id="${id}" style="...">内容</div>`);
requestAnimationFrame(() => {
  const el = document.getElementById(id);
  // 绑定事件
});
```

### ✅ 正确：createEl + addEventListener

```javascript
const card = container.createEl('a');
card.addEventListener('click', (e) => { e.preventDefault(); navigateTo(path); });
```

### ❌ 禁止：inline onclick

```html
<!-- 这在 Obsidian 中会被过滤，无法点击 -->
<a href="#" onclick="navigateTo('path')">文本</a>
```

### ❌ 禁止：变量重复声明

```javascript
let recentHtml = ''; // 如果已有同名 declared，会报错
// 务必使用唯一变量名
```

## 六、如何添加新模块

### 步骤

1. **找到插入点**：在文件中搜索 `// 模块 N:` 找到你要插入的位置
2. **选择渲染方式**：
   - 纯展示 → `dv.paragraph()` + 唯一 ID
   - 需要交互 → `dv.el()` + `innerHTML` + `querySelectorAll` 绑定事件
   - 复杂 DOM → `document.createElement()` + `addEventListener`
3. **使用色彩系统**：引用 `${C.card}`, `${C.accent}` 等变量
4. **JS 语法验证**：运行 `node -e "new Function(code)"` 确保无语法错误
5. **刷新 Obsidian**（Ctrl+E 切换阅读模式，或 Cmd+Shift+P → Reload）

### 模板代码

```javascript
// ============================================================
//  模块 N: 新模块名称 — 渲染方式说明
// ============================================================
const newId = 'new-' + Date.now();
dv.paragraph(`<div id="${newId}" style="background:${C.card};border-radius:16px;padding:16px 20px;margin-bottom:16px;border:1px solid ${C.border};box-shadow:0 2px 12px rgba(0,0,0,0.05);">
  <div style="font-size:15px;font-weight:600;color:${C.text};margin-bottom:10px;">🎯 模块标题</div>
  <div>模块内容</div>
</div>`);
requestAnimationFrame(() => {
  const el = document.getElementById(newId);
  if (el) {
    el.querySelectorAll('a[data-path]').forEach(a => {
      a.addEventListener('click', (e) => { e.preventDefault(); navigateTo(a.dataset.path); });
    });
  }
});
```

## 八、常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 点击不跳转 | inline onclick 被 Obsidian 过滤 | 改用 `addEventListener` |
| 变量重复声明 | 同名变量在不同模块中出现 | 使用唯一前缀（如 `podRecHtml`, `vizId`） |
| 页面空白 | JS 语法错误 | `node -e "new Function(code)"` 检查 |
| dv.el 重复渲染 | `dv.el('div','')` 与 innerHTML 冲突 | 改用 `dv.paragraph()` + requestAnimationFrame |
| 模块间距不均 | `dv.paragraph()` 有 `<p>` 包裹 | 全部 `margin-bottom:16px` 统一 |
| 双列不对齐 | grid 默认 stretch | 加 `align-items:start` |
