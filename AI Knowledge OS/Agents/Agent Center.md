# Agent Center

AI Agent 不以"会聊天"为标准，而以输入边界、工具权限、输出格式和验收方式为标准。

> [!info] 当前 AI 引擎
> 使用 **CodeBuddy Agent**（已加载 obsidian-knowledge-os Skill）替代原 Claudian。
> 在 CodeBuddy 中直接说出 Agent 角色名即可激活对应工作流。

## 我的 AI 员工

### 内容助手

**职责**：从现有知识生成公众号、短视频或提案草稿，并保留来源链接。

**调用方式**：在 CodeBuddy 中说"用内容助手写一篇关于 XX 的文章"

**工作流**：
1. 搜索 Vault 中与主题相关的所有笔记
2. 提取 rating ≥3 的高价值笔记
3. 列出引用来源与核心矛盾
4. 按照内容生产模板生成稿件
5. 保存到工作/ 或 03Life os/日常收藏/

### 商业分析助手

**职责**：分析企业客户、场景价值、采购阻力和落地路径。

**调用方式**：在 CodeBuddy 中说"用商业分析助手分析 XX 企业场景"

**工作流**：
1. 业务问题 → 现有流程 → 信息缺口 → AI 介入点 → 验收指标 → 实施风险
2. 结合 Vault 中已有的 AI Agent、FDE、企业 AI 转型 笔记
3. 输出到工作/ 或 AI Knowledge OS/Analytics/

### 学习助手

**职责**：把论文、课程和资料转成可复用的概念、证据与问题。

**调用方式**：在 CodeBuddy 中说"用学习助手分析这篇资料"

**工作流**：
1. 区分原文结论、作者证据和你的推断
2. 输出关键概念、反例、适用边界
3. 链接到已有笔记
4. 按知识笔记模板写入主知识库

## 常用批量命令

| 你说的 | Agent 做的 |
|--------|-----------|
| "处理 Inbox" | 读 Inbox → 分析 → 分类 → 路由分发到主知识库 |
| "找孤立笔记" | 全库扫描 → 列出 0 入链 + 0 出链 的笔记 |
| "生成周报" | 统计本周知识增长 → 分析缺口 → 输出报告 |
| "批量打标签" | 扫描指定目录 → 推荐标签 → 写入 frontmatter |
