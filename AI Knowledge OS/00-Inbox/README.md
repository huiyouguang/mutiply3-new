# Inbox

这里存放尚未整理的信息。

## 处理方式

在 CodeBuddy 中说"**处理 Inbox**"，Agent 会自动：
1. 读取所有待处理文件
2. 分析内容，识别领域和类型
3. 按知识笔记模板生成完整笔记
4. 推荐标签和 Wikilink
5. 按 domain 路由分发到主知识库对应目录
6. 清理 Inbox 中的原始文件

## 手动处理原则

处理每条信息时只做三个判断：

1. 是否值得保留？
2. 它属于哪个可复用概念或项目？
3. 下一步是什么？

> [!todo] Inbox 清空规则
> 不追求每天清空；每周至少处理一次。整理后移动到外层主知识库对应目录，并补充至少一个 Wikilink。
