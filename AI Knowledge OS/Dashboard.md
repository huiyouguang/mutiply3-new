## 三种 Agent 角色

| Agent | 触发词 | 功能 |
|-------|--------|------|
| 📝 内容助手 | "内容助手 + 主题" | 从知识笔记生成文章/视频稿/提案 |
| 📊 商业分析 | "分析XX企业场景" | 六步法分析企业 AI 落地 |
| 🎓 学习助手 | "分析这篇资料" | 论文/课程转可复用知识笔记 |
