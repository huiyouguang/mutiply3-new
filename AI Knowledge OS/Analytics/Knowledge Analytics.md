# Knowledge Analytics

动态指标通过 CodeBuddy Agent 生成。在 CodeBuddy 中说以下命令即可：

## 分析命令

| 命令 | 功能 |
|------|------|
| "生成周报" | 统计本周知识增长、标签分布、给出下周建议 |
| "知识分析" | 全库笔记统计、内部链接数、领域分布 |
| "找孤立笔记" | 检测 0 入链 + 0 出链 的笔记并给出连接建议 |
| "检查知识缺口" | 分析核心领域的信息覆盖度 |

## 每周复盘

在 CodeBuddy 中说"生成周报"即可自动回答以下问题：

- [ ] Inbox 中哪些内容应删除、整理或连接？
- [ ] 本周新增了哪些真正可复用的判断？
- [ ] 哪个项目缺少明确下一步？
- [ ] 哪些 AI 输出已经沉淀成模板或方法？
- [ ] 哪些笔记长期没有连接到真实项目？

## 插件内置分析

AI Knowledge OS 插件的知识驾驶舱会实时计算：
- 笔记数、内部链接数和未完成任务数
- 最近更新的知识与高频标签
- 文件夹分布与知识网络密度

> 深度分析由 CodeBuddy Agent（加载 obsidian-knowledge-os Skill）执行。
