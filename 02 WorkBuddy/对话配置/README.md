# WorkBuddy 对话配置中心

> 统一归档**每次对话**的关键内容，按主题 / 项目 / 日期分门别类，便于检索与跨对话复用。
> 这是对话产出的单一真相源（single source of truth），不与具体插件目录混放。

## 分类规则
- **文件命名**：`主题_YYYY-MM-DD.md`（主题用短词，如 `xove-thino-patch`；同一主题多次对话用日期区分）
- **分门别类方式**：每个主题一个文件；跨主题用不同文件；本 README 的索引表统一登记
- **放置位置**：本文件夹 `mutiply3/02 WorkBuddy/对话配置/`

## 同步机制（如何保证"每次对话都同步"）
- 本约定已写入 AI 记忆并持久化。AI 在**参与的每次对话**中，会在关键节点主动把要点 / 产出写入本文件夹对应文件，并在下方索引表追加一行。
- 说明：当前运行环境没有"对话启动自动钩子"，因此依赖 AI 记忆约定来执行；用户也可在对话开头说「归档到对话配置」显式触发。
- 建议：对话中如产生可复用代码 / 补丁 / 配置，结束时确认已归档。
