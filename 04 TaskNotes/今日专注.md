## 今日专注（数据来自 focus-time）

> [!note] 逻辑自洽说明
> 专注的唯一数据源是 **focus-time** 插件：每次专注会话由它写入 `04 TaskNotes/健康数据/YYYY-MM-DD.md` 的「⏱️ 专注（focus-time 插件）」段。
> 本笔记通过 Dataview 动态嵌入当天的专注记录，使 home-pages 主页只作为「视图」读取 focus-time 数据，不再维护独立历史——两端保持一致，无重复落盘。

```dataviewjs
const d = dv.date('today').toFormat('yyyy-MM-dd');
const link = '04 TaskNotes/健康数据/' + d + '.md#⏱️ 专注（focus-time 插件）';
dv.header(3, '⏱️ 专注 · ' + d);
try {
  await dv.embed(link);
} catch (e) {
  dv.paragraph('今日暂无专注记录，用 focus-time 开始一次专注后会自动出现在这里。');
}
```
